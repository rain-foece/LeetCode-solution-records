# 只出现一次的数字（Single Number）题解

> 题目链接：[LeetCode 136. Single Number](https://leetcode.cn/problems/single-number/)

## 题目描述

给你一个**非空**整数数组 `nums`，除了某个元素只出现一次以外，其余每个元素均出现两次。找出那个只出现了一次的元素。

你必须设计并实现线性时间复杂度的算法来解决此问题，且该算法只使用常量额外空间。

**示例 1：**

```
输入：nums = [2,2,1]
输出：1
```

**示例 2：**

```
输入：nums = [4,1,2,1,2]
输出：4
```

**示例 3：**

```
输入：nums = [1]
输出：1
```

## 题引：无尽孤独

> 想象你是在 L 星球灵魂市场寻找自己灵魂的小 Z，你把自己拆成了二进制数，每一位代表自己某个特点（无好坏倾向），1 代表你满足这个条件，0 表示不满足。
>
> L 星球有一个特殊的规矩，每个人找到的灵魂必须是和自己条件一模一样的灵魂，而且每次开放灵魂市场时总会有一个人找不到自己的灵魂，这个人将会成为守卫灵魂市场的人。
>
> 相亲现场有一个匹配区域，在匹配区域里面，你可以上传自己的个人信息，也可以在信息池里寻找灵魂的信息。
>
> 信息池子有个特殊的设定，每个条件对应一个小池，每次进去一个人，信息池就会把这个人的情况拆分并放入对应的小池（二进制位匹配），如果与池中现存的数相同，那么就把这个小池设置为 0，如果两个数不相同，那就设置为 1。
>
> 随着一个又一个人在市场中找到了自己的灵魂，小 A 盯着池子中的数字一次次变化。最终，场馆中只剩下了小 A 一个人，此时的他并未察觉，直到他看到池子里面锁定的数字，一位一位，都和自己一样。小 A 眼中却看不到兴奋，因为他知道这个机器的运作规律，也看透了自己的命运。
>
> 有些人，注定孤独……

这个"信息池"的设定，就是**异或运算**的本质——相同归零，相异归一。

---

## 核心思路

异或运算（XOR, `^`）有三个关键性质：

1. **归零律**：`a ^ a = 0`（相同的数异或得 0）
2. **恒等律**：`a ^ 0 = a`（和 0 异或等于自身）
3. **交换律 & 结合律**：`a ^ b ^ a = (a ^ a) ^ b = 0 ^ b = b`

数组中所有成对的元素异或后会互相抵消归零，最后剩下的就是那个只出现一次的数。

```
[4, 1, 2, 1, 2]
→ 4 ^ 1 ^ 2 ^ 1 ^ 2
→ 4 ^ (1 ^ 1) ^ (2 ^ 2)   （交换律+结合律，把相同的挪到一起）
→ 4 ^ 0 ^ 0
→ 4
```

---

## 代码

```cpp
class Solution {
public:
    int singleNumber(vector<int>& nums) {
        int ans = 0;
        for (int i : nums) ans ^= i;
        return ans;
    }
};
```

---

## 代码分析

就一行核心逻辑 `ans ^= i`，本质上就是上面那个"信息池"的运作方式：

- 每个二进制位独立异或。
- 出现两次的数字，每个位都被翻转两次，回到 0。
- 出现一次的数字，每个位被翻转一次，保留下来。

以 `nums = [4, 1, 2, 1, 2]` 为例，用二进制看：

```
4 = 100
1 = 001
2 = 010
1 = 001
2 = 010
```

逐位异或（只看最低两位就够了，因为最高位只有 4 有）：

| 步骤 | 操作 | ans（二进制） | ans（十进制） |
|:---:|------|:---:|:---:|
| 初始 | ans = 0 | `000` | 0 |
| 1 | `ans ^= 4` | `100` | 4 |
| 2 | `ans ^= 1` | `101` | 5 |
| 3 | `ans ^= 2` | `111` | 7 |
| 4 | `ans ^= 1` | `110` | 6 |
| 5 | `ans ^= 2` | `100` | **4** |

最终 `ans = 4`，正是那个孤独的数字。

## 复杂度分析

| 指标 | 值 |
|:---|:---|
| 时间复杂度 | O(n) |
| 空间复杂度 | O(1) |

遍历数组一次，只用了一个变量 `ans`，严格满足题目要求的线性时间和常量空间。

## 总结

这道题是异或运算的经典应用，代码极短但思想深刻。核心在于抓住异或的三个性质：

- **归零律** `a ^ a = 0` → 成对元素互相抵消
- **恒等律** `a ^ 0 = a` → 0 不改变结果
- **交换律 & 结合律** → 顺序无关，可以任意重组

变体问题：
- 136. 只出现一次的数字 → 一个数出现一次，其余出现两次（本题）
- 137. 只出现一次的数字 II → 一个数出现一次，其余出现三次
- 260. 只出现一次的数字 III → 两个数各出现一次，其余出现两次

137 需要按位统计（每个位上 1 的个数 mod 3），260 需要先全员异或再按某一位分组。三者都是异或思想的延伸，可以对照学习。
