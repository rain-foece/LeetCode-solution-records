# 乘积最大子数组（Maximum Product Subarray）题解

> 题目链接：[LeetCode 152. Maximum Product Subarray](https://leetcode.cn/problems/maximum-product-subarray/)

## 题目描述

给你一个整数数组 `nums`，请你找出数组中乘积最大的非空连续子数组（该子数组中至少包含一个数字），并返回该子数组所对应的乘积。

一个只包含一个元素的数组的乘积是这个元素的值。

- `1 <= nums.length <= 2 * 10⁴`
- `-10 <= nums[i] <= 10`

**示例 1：**

```
输入: nums = [2,3,-2,4]
输出: 6
解释: 子数组 [2,3] 有最大乘积 6。
```

**示例 2：**

```
输入: nums = [-2,0,-1]
输出: 0
解释: 结果不能为 2, 因为 [-2,-1] 不是子数组。
```

---

## 核心思路

我们不能简单的用滑动窗口一遍过，因为这道题存在负数，而我们知道两个负数的乘积是正数。如果我们浅显地遇到负数就跳过，很可能损失最大值。

和 53. 最大子数组和不同，乘积的难点在于**符号翻转**：一个很小的负数，乘以一个新的负数，可能变成一个很大的正数。所以我们要用两个值记录以当前数字结尾的子数组：一是**最大正值**，一是**最小负值**（因为负负得正，最小值可能反转成最大值）。

状态转移：对于当前元素 `val`，以它结尾的最大乘积和最小乘积分别来自三种可能：

- `pos * val`：前一个最大正值 × 当前值
- `neg * val`：前一个最小负值 × 当前值（可能负负得正）
- `val`：当前值单独成段（放弃前面的累积）

取三者中的最大和最小，就是新的 `pos` 和 `neg`。

## 代码

```cpp
class Solution {
public:
    int maxProduct(vector<int>& nums) {
        int pos = nums[0], neg = nums[0];      // 以当前元素结尾的最大/最小乘积
        int n = nums.size();
        int ans = nums[0];

        for (int i = 1; i < n; ++i) {
            int val = nums[i];
            int tmp_pos = pos, tmp_neg = neg;  // 暂存旧值，因为 pos/neg 会互相依赖

            pos = max({tmp_pos * val, tmp_neg * val, val});
            neg = min({tmp_pos * val, tmp_neg * val, val});
            ans = max(ans, pos);
        }
        return ans;
    }
};
```

---

## 代码分析

### 两个状态变量

```cpp
int pos = nums[0], neg = nums[0];
```

- `pos`：以**当前元素结尾**的子数组的**最大乘积**。
- `neg`：以**当前元素结尾**的子数组的**最小乘积**（通常是负数，等待被另一个负数翻转）。

两者都初始化为 `nums[0]`，因为只有一个元素时，最大和最小都是它本身。

### 暂存旧值

```cpp
int tmp_pos = pos, tmp_neg = neg;
```

这是关键细节。`pos` 和 `neg` 的新值都依赖旧的 `pos` 和 `neg`，如果直接更新，`neg` 的计算会用到已经被覆盖的 `pos`。所以必须先用 `tmp_pos` 和 `tmp_neg` 暂存旧值。

### 状态转移

```cpp
pos = max({tmp_pos * val, tmp_neg * val, val});
neg = min({tmp_pos * val, tmp_neg * val, val});
```

三种选择：

1. **`tmp_pos * val`**：延续之前的正乘积。如果 `val > 0`，正 × 正 = 更大正；如果 `val < 0`，正 × 负 = 负。
2. **`tmp_neg * val`**：延续之前的负乘积。如果 `val < 0`，负 × 负 = 正（翻转！）；如果 `val > 0`，负 × 正 = 更小负。
3. **`val`**：放弃前面的累积，当前元素单独成段。当 `val = 0` 时，`pos` 和 `neg` 都归零，下一轮重新开始。

`max` 取最大（正），`min` 取最小（负），两者同时维护，覆盖了"负负得正"的翻转情况。

### 更新答案

```cpp
ans = max(ans, pos);
```

全局最大乘积一定是某个位置的最大正值 `pos`。不需要考虑 `neg`，因为 `neg` 是负数，不可能成为最大值（除非全负，此时 `pos` 也会是最大的那个负数）。

## 逐轮推演

以 `nums = [2, 3, -2, 4]` 为例：

| 轮次 | i | val | tmp_pos | tmp_neg | pos = max(三项) | neg = min(三项) | ans |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| 初始 | 0 | 2 | — | — | 2 | 2 | 2 |
| 1 | 1 | 3 | 2 | 2 | max(6, 6, 3)=6 | min(6, 6, 3)=3 | 6 |
| 2 | 2 | -2 | 6 | 3 | max(-12, -6, -2)=-2 | min(-12, -6, -2)=-12 | 6 |
| 3 | 3 | 4 | -2 | -12 | max(-8, -48, 4)=4 | min(-8, -48, 4)=-48 | 6 |

`ans = 6`，来自子数组 `[2, 3]`。注意第 2 轮 `pos = -2`（单独取 `-2`），`neg = -12`（`6 × -2`），第 3 轮 `pos = 4`（单独取 `4`），虽然 `neg = -48` 但 `ans` 始终是 6。

---

以 `nums = [-2, 3, -4]` 为例（展示负负得正）：

| 轮次 | i | val | tmp_pos | tmp_neg | pos = max(三项) | neg = min(三项) | ans |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| 初始 | 0 | -2 | — | — | -2 | -2 | -2 |
| 1 | 1 | 3 | -2 | -2 | max(-6, -6, 3)=3 | min(-6, -6, 3)=-6 | 3 |
| 2 | 2 | -4 | 3 | -6 | max(-12, 24, -4)=24 | min(-12, 24, -4)=-12 | 24 |

第 2 轮，`tmp_neg * val = -6 × -4 = 24`，负负得正，`pos = 24`，`ans = 24`。整个数组 `[-2, 3, -4]` 的乘积就是 24。

---

以 `nums = [0, 2]` 为例（展示零的处理）：

| 轮次 | i | val | tmp_pos | tmp_neg | pos = max(三项) | neg = min(三项) | ans |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| 初始 | 0 | 0 | — | — | 0 | 0 | 0 |
| 1 | 1 | 2 | 0 | 0 | max(0, 0, 2)=2 | min(0, 0, 2)=0 | 2 |

遇到 0 后，`pos` 和 `neg` 都归零，下一轮 `val = 2` 时"单独成段"重新开始，`pos = 2`。

## 复杂度分析

- **时间复杂度**：O(n)，一次遍历。
- **空间复杂度**：O(1)，只用了几个变量。

## 总结

这道题的核心是**同时维护最大和最小两个状态**，因为负负得正，最小值随时可能翻转成最大值。

三个关键点：

1. **两个状态**：`pos`（最大正乘积）和 `neg`（最小负乘积），缺一不可。
2. **三种选择**：延续正乘积、延续负乘积、单独成段，取 max/min。
3. **暂存旧值**：`tmp_pos` 和 `tmp_neg` 保证更新时互不干扰。

和 53. 最大子数组和相比，53 只需要维护一个最大值（加法不会改变符号），152 需要同时维护最大值和最小值（乘法会改变符号）。和 198. 打家劫舍（抢/不抢两种状态）类似，152 也是"同一位置维护多个状态"的 DP，只不过状态不是"选/不选"，而是"最大/最小"。这种"双状态"思想在涉及符号翻转的场景中非常实用。
