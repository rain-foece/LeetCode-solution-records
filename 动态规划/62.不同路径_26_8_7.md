# 不同路径（Unique Paths）题解

> 题目链接：[LeetCode 62. Unique Paths](https://leetcode.cn/problems/unique-paths/)

## 题目描述

一个机器人位于一个 `m x n` 网格的左上角（起始点在下图中标记为 "Start"）。

机器人每次只能向下或者向右移动一步。机器人试图达到网格的右下角（在下图中标记为 "Finish"）。

问总共有多少条不同的路径？

**示例 1：**

```
输入：m = 3, n = 7
输出：28
```

**示例 2：**

```
输入：m = 3, n = 2
输出：3
解释：
从左上角开始，总共有 3 条路径可以到达右下角。
1. 向右 -> 向下 -> 向下
2. 向下 -> 向下 -> 向右
3. 向下 -> 向右 -> 向下
```

**示例 3：**

```
输入：m = 7, n = 3
输出：28
```

**示例 4：**

```
输入：m = 3, n = 3
输出：6
```

---

## 核心思路

很明显的多维 DP。

设 `dp[i][j]` 表示从起点 `(1, 1)` 走到 `(i, j)` 的路径数。机器人每次只能**向下**或**向右**移动一步，那么到达 `(i, j)` 的上一步只可能是：

- 从上方 `(i-1, j)` 向下走一步
- 从左侧 `(i, j-1)` 向右走一步

因此状态转移方程：

```
dp[i][j] = dp[i-1][j] + dp[i][j-1]
```

边界条件：起点 `dp[1][1] = 1`（只有一种方式站在起点）。

这本质上是一个二维的斐波那契数列——每个格子的值等于它左边和上边格子的值之和。如果画出来，你会发现这就是**杨辉三角（帕斯卡三角）**的二维推广。

## 版本一：二维 DP

### 代码

```cpp
class Solution {
public:
    int uniquePaths(int m, int n) {
        vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));
        dp[1][1] = 1;
        for (int i = 1; i <= m; ++i) {
            for (int j = 1; j <= n; ++j) {
                if (i == 1 && j == 1) continue;
                dp[i][j] = dp[i - 1][j] + dp[i][j - 1];
            }
        }
        return dp[m][n];
    }
};
```

### 代码分析

- `dp[i][j]` 表示从 `(1, 1)` 到 `(i, j)` 的路径数。
- 多开一行一列 `(m+1) × (n+1)`，初始化为 0，避免处理 `i-1` 或 `j-1` 越界的情况。
- `dp[1][1] = 1`：起点。
- 循环中跳过 `(1, 1)`，因为已经初始化好了。
- 状态转移：`dp[i][j] = dp[i-1][j] + dp[i][j-1]`——上方路径数 + 左侧路径数。

### 逐轮推演

以 `m = 3, n = 3` 为例，`dp` 数组变化过程：

| i\j | 1 | 2 | 3 |
|:---:|:---:|:---:|:---:|
| 初始 | 0 | 0 | 0 |
| 初始 | 0 | 0 | 0 |
| 初始 | 0 | 0 | 0 |

**i=1, j=1**：跳过（起点已设为 1）

| i\j | 1 | 2 | 3 |
|:---:|:---:|:---:|:---:|
| 1 | **1** | — | — |
| 2 | 0 | 0 | 0 |
| 3 | 0 | 0 | 0 |

**i=1, j=2**：`dp[1][2] = dp[0][2] + dp[1][1] = 0 + 1 = 1`

| i\j | 1 | 2 | 3 |
|:---:|:---:|:---:|:---:|
| 1 | 1 | **1** | — |
| 2 | 0 | 0 | 0 |
| 3 | 0 | 0 | 0 |

**i=1, j=3**：`dp[1][3] = dp[0][3] + dp[1][2] = 0 + 1 = 1`

第一行全部为 1（只有一直向右走这一种方式）。

| i\j | 1 | 2 | 3 |
|:---:|:---:|:---:|:---:|
| 1 | 1 | 1 | **1** |
| 2 | 0 | 0 | 0 |
| 3 | 0 | 0 | 0 |

**i=2, j=1**：`dp[2][1] = dp[1][1] + dp[0][1] = 1 + 0 = 1`

第一列也全为 1（只有一直向下走这一种方式）。

| i\j | 1 | 2 | 3 |
|:---:|:---:|:---:|:---:|
| 1 | 1 | 1 | 1 |
| 2 | **1** | — | — |
| 3 | 0 | 0 | 0 |

**i=2, j=2**：`dp[2][2] = dp[1][2] + dp[2][1] = 1 + 1 = 2`

| i\j | 1 | 2 | 3 |
|:---:|:---:|:---:|:---:|
| 1 | 1 | 1 | 1 |
| 2 | 1 | **2** | — |
| 3 | 0 | 0 | 0 |

**i=2, j=3**：`dp[2][3] = dp[1][3] + dp[2][2] = 1 + 2 = 3`

| i\j | 1 | 2 | 3 |
|:---:|:---:|:---:|:---:|
| 1 | 1 | 1 | 1 |
| 2 | 1 | 2 | **3** |
| 3 | 0 | 0 | 0 |

**i=3, j=1**：`dp[3][1] = dp[2][1] + dp[0][1] = 1 + 0 = 1`

| i\j | 1 | 2 | 3 |
|:---:|:---:|:---:|:---:|
| 1 | 1 | 1 | 1 |
| 2 | 1 | 2 | 3 |
| 3 | **1** | — | — |

**i=3, j=2**：`dp[3][2] = dp[2][2] + dp[3][1] = 2 + 1 = 3`

| i\j | 1 | 2 | 3 |
|:---:|:---:|:---:|:---:|
| 1 | 1 | 1 | 1 |
| 2 | 1 | 2 | 3 |
| 3 | 1 | **3** | — |

**i=3, j=3**：`dp[3][3] = dp[2][3] + dp[3][2] = 3 + 3 = 6`

| i\j | 1 | 2 | 3 |
|:---:|:---:|:---:|:---:|
| 1 | 1 | 1 | 1 |
| 2 | 1 | 2 | 3 |
| 3 | 1 | 3 | **6** |

最终 `dp[3][3] = 6`，即 3×3 网格有 6 条不同路径。

## 版本二：空间优化（一维 DP）

### 核心思路

观察状态转移方程 `dp[i][j] = dp[i-1][j] + dp[i][j-1]`：

- `dp[i-1][j]` 是上一行同列的值（上方）
- `dp[i][j-1]` 是本行前一列的值（左侧）

当我们按行遍历时，`dp[i][j-1]` 刚刚被更新过（本行），`dp[i-1][j]` 还保留着上一轮的值（上一行）。这意味着我们可以**只用一维数组**，在遍历过程中就地更新：

```
dp[j] = dp[j] + dp[j-1]
        ↑        ↑
     上一行的值  本行刚更新的值
```

### 代码

```cpp
class Solution {
public:
    int uniquePaths(int m, int n) {
        vector<int> dp(n, 0);
        dp[0] = 1;
        for (int k = 0; k < m; ++k) {
            for (int j = 1; j < n; ++j) {
                dp[j] += dp[j - 1];
            }
        }
        return dp[n - 1];
    }
};
```

### 代码分析

- `dp[j]` 表示当前行走到第 `j` 列的路径数。
- `dp[0] = 1`：第一列始终为 1（只有一直向下走这一种方式），每轮循环不变。
- 外层循环 `k` 遍历每一行，内层从 `j=1` 开始（`dp[0]` 已经是 1，不需要更新）。
- `dp[j] += dp[j-1]`：`dp[j]` 目前是上一行同列的值（`dp[i-1][j]`），加上 `dp[j-1]`（本行前一列的值 `dp[i][j-1]`），得到当前格子的值。

### 逐轮推演

以 `m = 3, n = 3` 为例，`dp` 数组初始：`[1, 0, 0]`

**第 1 行（k=0）**：

| j | 操作 | dp |
|:---:|------|:---|
| 初始 | — | `[1, 0, 0]` |
| j=1 | `dp[1] += dp[0]` → 0+1=1 | `[1, 1, 0]` |
| j=2 | `dp[2] += dp[1]` → 0+1=1 | `[1, 1, 1]` |

第 1 行结束后 `dp = [1, 1, 1]`，对应 `[dp[1][1], dp[1][2], dp[1][3]]`。

**第 2 行（k=1）**：

| j | 操作 | dp |
|:---:|------|:---|
| 初始 | — | `[1, 1, 1]` |
| j=1 | `dp[1] += dp[0]` → 1+1=2 | `[1, 2, 1]` |
| j=2 | `dp[2] += dp[1]` → 1+2=3 | `[1, 2, 3]` |

第 2 行结束后 `dp = [1, 2, 3]`，对应 `[dp[2][1], dp[2][2], dp[2][3]]`。

**第 3 行（k=2）**：

| j | 操作 | dp |
|:---:|------|:---|
| 初始 | — | `[1, 2, 3]` |
| j=1 | `dp[1] += dp[0]` → 2+1=3 | `[1, 3, 3]` |
| j=2 | `dp[2] += dp[1]` → 3+3=6 | `[1, 3, 6]` |

第 3 行结束后 `dp = [1, 3, 6]`，对应 `[dp[3][1], dp[3][2], dp[3][3]]`。

最终 `dp[2] = 6`，与二维版本一致。

## 扩展：组合数学解法

这道题本质上是一个组合问题：从 `(1, 1)` 到 `(m, n)`，总共需要走 `m-1` 步向下和 `n-1` 步向右，共 `m+n-2` 步。问题转化为：在 `m+n-2` 步中选择 `m-1` 步向下（其余向右），即：

```
C(m+n-2, m-1) = (m+n-2)! / ((m-1)! × (n-1)!)
```

```cpp
class Solution {
public:
    int uniquePaths(int m, int n) {
        long long ans = 1;
        // C(m+n-2, m-1) = C(m+n-2, n-1)，取较小者减少计算量
        int k = min(m - 1, n - 1);
        int total = m + n - 2;
        for (int i = 1; i <= k; ++i) {
            ans = ans * (total - k + i) / i;
        }
        return (int)ans;
    }
};
```

时间复杂度 O(min(m, n))，空间复杂度 O(1)。不过需要注意溢出问题，这里用了 `long long`，且边乘边除保证中间结果不溢出。

---

## 复杂度分析

| 版本 | 时间复杂度 | 空间复杂度 |
|:---:|:---:|:---:|
| 版本一（二维 DP） | O(m × n) | O(m × n) |
| 版本二（一维 DP） | O(m × n) | O(n) |
| 扩展（组合数学） | O(min(m, n)) | O(1) |

三种版本时间复杂度都在 O(m × n) 或更优的级别。空间上版本二将二维数组压缩到一维，版本三更是常数级空间。

## 总结

这道题是网格 DP 的入门题，核心思想非常清晰：

1. **二维 DP**：`dp[i][j] = dp[i-1][j] + dp[i][j-1]`，每个格子只依赖上方和左侧，天然适合 DP。
2. **一维 DP**：观察发现只需要上一行的值，压缩到一个一维数组，`dp[j] += dp[j-1]` 就地更新。这种「滚动数组」技巧在 70. 爬楼梯、198. 打家劫舍等题中也反复出现。
3. **组合数学**：将问题抽象为排列组合，直接公式求解，时间和空间都最优。

这道题和 70. 爬楼梯一脉相承——70 是「一维路径计数」（每次走 1 或 2 步），62 是「二维路径计数」（每次向右或向下）。两者的状态转移都是「当前 = 来自上一步的方案数之和」，区别在于 70 是一维递推，62 是二维递推。
