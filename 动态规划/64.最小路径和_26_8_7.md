# 最小路径和（Minimum Path Sum）题解

> 题目链接：[LeetCode 64. Minimum Path Sum](https://leetcode.cn/problems/minimum-path-sum/)

## 题目描述

给定一个包含非负整数的 `m x n` 网格 `grid`，请找出一条从左上角到右下角的路径，使得路径上的数字总和为最小。

**每次只能向下或者向右移动一步。**

**示例 1：**

```
输入：grid = [[1,3,1],[1,5,1],[4,2,1]]
输出：7
解释：路径 1 → 3 → 1 → 1 → 1 的总和最小。
```

**示例 2：**

```
输入：grid = [[1,2,3],[4,5,6]]
输出：12
```

---

## 核心思路

和上一道题 62. 不同路径如出一辙，只要搞明白每次只能从**上面**来和从**左边**来就够了。

设 `dp[i][j]` 表示从起点 `(0, 0)` 走到 `(i, j)` 的最小路径和。到达 `(i, j)` 的上一步有两种可能：

- 从上方 `(i-1, j)` 向下走一步
- 从左侧 `(i, j-1)` 向右走一步

两者取最小值，再加上当前格子的值：

```
dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j]
```

这和 62 题的差别只有一处：62 是**求和**（`dp[i-1][j] + dp[i][j-1]`），64 是**取 min 后加**（`min(dp[i-1][j], dp[i][j-1]) + grid[i][j]`）。

## 版本一：二维 DP

### 代码

```cpp
class Solution {
public:
    int minPathSum(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size();
        vector<vector<int>> dp(m, vector<int>(n, 0));
        dp[0][0] = grid[0][0];

        // 第一行：只能从左边来
        for (int j = 1; j < n; ++j) {
            dp[0][j] = dp[0][j - 1] + grid[0][j];
        }

        // 第一列：只能从上面来
        for (int i = 1; i < m; ++i) {
            dp[i][0] = dp[i - 1][0] + grid[i][0];
        }

        // 其余格子：min(上方, 左侧) + 当前值
        for (int i = 1; i < m; ++i) {
            for (int j = 1; j < n; ++j) {
                dp[i][j] = min(dp[i - 1][j], dp[i][j - 1]) + grid[i][j];
            }
        }
        return dp[m - 1][n - 1];
    }
};
```

### 代码分析

- 第一行和第一列单独处理，因为边界格子只有一种来源（第一行只能从左来，第一列只能从上来）。
- 内部格子取 `min(dp[i-1][j], dp[i][j-1])` 再加当前值。
- 时间复杂度 O(m × n)，空间复杂度 O(m × n)。

### 逐轮推演

以 `grid = [[1,3,1],[1,5,1],[4,2,1]]` 为例：

**初始化第一行和第一列**：

| i\j | 0 | 1 | 2 |
|:---:|:---:|:---:|:---:|
| 0 | **1** | 1+3=**4** | 4+1=**5** |
| 1 | 1+1=**2** | — | — |
| 2 | 2+4=**6** | — | — |

**i=1, j=1**：`dp[1][1] = min(dp[0][1], dp[1][0]) + 5 = min(4, 2) + 5 = 7`

| i\j | 0 | 1 | 2 |
|:---:|:---:|:---:|:---:|
| 0 | 1 | 4 | 5 |
| 1 | 2 | **7** | — |
| 2 | 6 | — | — |

**i=1, j=2**：`dp[1][2] = min(dp[0][2], dp[1][1]) + 1 = min(5, 7) + 1 = 6`

| i\j | 0 | 1 | 2 |
|:---:|:---:|:---:|:---:|
| 0 | 1 | 4 | 5 |
| 1 | 2 | 7 | **6** |
| 2 | 6 | — | — |

**i=2, j=1**：`dp[2][1] = min(dp[1][1], dp[2][0]) + 2 = min(7, 6) + 2 = 8`

| i\j | 0 | 1 | 2 |
|:---:|:---:|:---:|:---:|
| 0 | 1 | 4 | 5 |
| 1 | 2 | 7 | 6 |
| 2 | 6 | **8** | — |

**i=2, j=2**：`dp[2][2] = min(dp[1][2], dp[2][1]) + 1 = min(6, 8) + 1 = 7`

| i\j | 0 | 1 | 2 |
|:---:|:---:|:---:|:---:|
| 0 | 1 | 4 | 5 |
| 1 | 2 | 7 | 6 |
| 2 | 6 | 8 | **7** |

最终 `dp[2][2] = 7`，对应路径 `1 → 3 → 1 → 1 → 1`（`grid[0][0] → grid[0][1] → grid[1][1] → grid[1][2] → grid[2][2]`）。

## 版本二：空间优化（一维 DP）

### 核心思路

和 62 题一样，`dp[i][j]` 只依赖上一行同列的值（`dp[i-1][j]`）和本行前一列的值（`dp[i][j-1]`），可以压缩到一维数组。

关键技巧：一维数组 `f` 多开一位，用 `INT_MAX` 初始化，`f[1] = 0`。这样 `min(f[j], f[j+1])` 自然处理了边界——第一列 `min(f[0]=INT_MAX, f[1])` 保证只能从上方来。

### 代码

```cpp
class Solution {
public:
    int minPathSum(vector<vector<int>>& grid) {
        int n = grid[0].size();
        vector<int> f(n + 1, INT_MAX);
        f[1] = 0;
        for (auto& row : grid) {
            for (int j = 0; j < n; ++j) {
                f[j + 1] = min(f[j], f[j + 1]) + row[j];
            }
        }
        return f[n];
    }
};
```

### 代码分析

- `f` 大小为 `n+1`，`f[0]` 始终为 `INT_MAX`（哨兵），`f[1]~f[n]` 存储当前行各列的最小路径和。
- `f[1] = 0`：起点的最小路径和初始为 0（还没加上 `grid[0][0]`）。
- 外层遍历每一行，内层遍历每一列：
  - `f[j]` 是当前行 `j-1` 列的值（左侧，刚更新过）
  - `f[j+1]` 是上一行 `j` 列的值（上方，还没被覆盖）
  - `min(f[j], f[j+1])` 取较小者，加上当前格子值 `row[j]`。

**哨兵 `INT_MAX` 的精妙之处**：处理第一列时，`f[0] = INT_MAX`，`min(INT_MAX, f[1])` 必然等于 `f[1]`（上方来的值），自然忽略了「左侧」这个不存在的位置。处理第一行时，`f[1]` 初始为 0，`f[2]~f[n]` 初始为 `INT_MAX`，所以 `min(f[j], INT_MAX)` 必然等于 `f[j]`（左侧来的值），自然忽略了「上方」这些不存在的值。

### 逐轮推演

以 `grid = [[1,3,1],[1,5,1],[4,2,1]]` 为例，`f` 初始：`[INT_MAX, 0, INT_MAX, INT_MAX]`（n=3，数组大小 4）

**第 1 行 `row = [1, 3, 1]`**：

| j | row[j] | f[j]（左侧） | f[j+1]（上方） | min | 新的 f[j+1] | f 数组 |
|:---:|:---:|:---:|:---:|:---:|:---|:---|
| 初始 | — | — | — | — | — | `[M, 0, M, M]` |
| 0 | 1 | M | 0 | 0 | 0+1=**1** | `[M, 1, M, M]` |
| 1 | 3 | 1 | M | 1 | 1+3=**4** | `[M, 1, 4, M]` |
| 2 | 1 | 4 | M | 4 | 4+1=**5** | `[M, 1, 4, 5]` |

第 1 行结束：`f = [M, 1, 4, 5]`，对应 `[dp[0][0], dp[0][1], dp[0][2]]`。

**第 2 行 `row = [1, 5, 1]`**：

| j | row[j] | f[j]（左侧） | f[j+1]（上方） | min | 新的 f[j+1] | f 数组 |
|:---:|:---:|:---:|:---:|:---:|:---|:---|
| 初始 | — | — | — | — | — | `[M, 1, 4, 5]` |
| 0 | 1 | M | 1 | 1 | 1+1=**2** | `[M, 2, 4, 5]` |
| 1 | 5 | 2 | 4 | 2 | 2+5=**7** | `[M, 2, 7, 5]` |
| 2 | 1 | 7 | 5 | 5 | 5+1=**6** | `[M, 2, 7, 6]` |

第 2 行结束：`f = [M, 2, 7, 6]`，对应 `[dp[1][0], dp[1][1], dp[1][2]]`。

**第 3 行 `row = [4, 2, 1]`**：

| j | row[j] | f[j]（左侧） | f[j+1]（上方） | min | 新的 f[j+1] | f 数组 |
|:---:|:---:|:---:|:---:|:---:|:---|:---|
| 初始 | — | — | — | — | — | `[M, 2, 7, 6]` |
| 0 | 4 | M | 2 | 2 | 2+4=**6** | `[M, 6, 7, 6]` |
| 1 | 2 | 6 | 7 | 6 | 6+2=**8** | `[M, 6, 8, 6]` |
| 2 | 1 | 8 | 6 | 6 | 6+1=**7** | `[M, 6, 8, 7]` |

第 3 行结束：`f = [M, 6, 8, 7]`，对应 `[dp[2][0], dp[2][1], dp[2][2]]`。

最终 `f[3] = 7`，与二维版本一致。

## 复杂度分析

| 版本 | 时间复杂度 | 空间复杂度 |
|:---:|:---:|:---:|
| 版本一（二维 DP） | O(m × n) | O(m × n) |
| 版本二（一维 DP） | O(m × n) | O(n) |

两次遍历无法避免（每个格子至少要访问一次），所以 O(m × n) 是时间下限。空间上版本二用 `INT_MAX` 哨兵技巧，统一处理边界，代码简洁度不输二维版本。

## 总结

这道题是 62. 不同路径的"求 min"变体，两者对比非常直观：

| | 62. 不同路径 | 64. 最小路径和 |
|:---|:---|:---|
| 状态定义 | `dp[i][j]` = 路径数 | `dp[i][j]` = 最小路径和 |
| 转移方程 | `dp[i][j] = dp[i-1][j] + dp[i][j-1]` | `dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j]` |
| 运算 | 求和 | 取 min 后加 |
| 边界 | 第一行/列全为 1 | 第一行/列累加 |

版本二的 `INT_MAX` 哨兵是亮点——用 `f[0] = INT_MAX` 和 `f[1] = 0` 两个初始值，一行代码 `min(f[j], f[j+1])` 就优雅地处理了所有边界情况，值得记住。类似的哨兵技巧在 155. 最小栈、4. 寻找两个正序数组的中位数、32. 最长有效括号中都有出现。
