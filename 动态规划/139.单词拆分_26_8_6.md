# 单词拆分（Word Break）题解

> 题目链接：[LeetCode 139. Word Break](https://leetcode.cn/problems/word-break/)

## 题目描述

给你一个字符串 `s` 和一个字符串列表 `wordDict` 作为字典。如果可以利用字典中出现的一个或多个单词拼接出 `s` 则返回 `true`。

注意：不要求字典中出现的单词全部都使用，并且字典中的单词可以重复使用。

- `1 <= s.length <= 300`
- `1 <= wordDict.length <= 1000`
- `1 <= wordDict[i].length <= 20`

**示例 1：**

```
输入: s = "leetcode", wordDict = ["leet", "code"]
输出: true
解释: 返回 true 因为 "leetcode" 可以由 "leet" 和 "code" 拼接成。
```

**示例 2：**

```
输入: s = "applepenapple", wordDict = ["apple", "pen"]
输出: true
解释: 返回 true 因为 "applepenapple" 可以由 "apple" "pen" "apple" 拼接成。
     注意，你可以重复使用字典中的单词。
```

**示例 3：**

```
输入: s = "catsandog", wordDict = ["cats", "dog", "sand", "and", "cat"]
输出: false
```

## 核心思路

这道题显然是一个动态规划问题。我们按照"先递归找思路，再翻译成递推"的步骤，一步步找出最优解。

定义 `dp[i]`：`s` 的前 `i` 个字符（即 `s[0..i-1]`）能否由字典中的单词拼接而成。

对于一个位置 `i`，我们检查：是否存在一个 `j < i`，使得 `s[j..i-1]` 是一个字典中的单词，且 `s[0..j-1]`（即 `dp[j]`）可以被拼接。如果存在，则 `dp[i] = true`。

```
dp[i] = true   ⇔   存在 j < i，使得 dp[j] = true 且 s[j..i-1] ∈ wordDict
```

**优化**：内层循环 `j` 从 `i-1` 往前扫，但不需要扫到 0——只需要扫到 `max(0, i - max_l)`，其中 `max_l` 是字典中最长单词的长度。因为比 `max_l` 更长的子串不可能是字典中的单词。

## 版本一：递归 + 记忆化

```cpp
class Solution {
public:
    bool wordBreak(string s, vector<string>& w) {
        unordered_set<string> hash(w.begin(), w.end());
        int max_l = ranges::max(w, {}, &string::size).size();
        vector<int> memo(s.size() + 1, -1);

        auto dfs = [&](this auto&& dfs, int i) -> bool {
            if (i == 0) return true;                // 空字符串，可以拼接
            int& res = memo[i];
            if (res != -1) return res;               // 记忆化

            // 从后往前枚举切割点 j，只枚举长度 ≤ max_l 的子串
            for (int j = i - 1; j >= max(0, i - max_l); --j) {
                if (hash.contains(s.substr(j, i - j)) && dfs(j))
                    return res = true;
            }
            return res = false;
        };

        return dfs(s.size());
    }
};
```

### 代码分析

**递归定义**：`dfs(i)` 表示 `s` 的前 `i` 个字符能否被拆分。从后往前枚举切割点 `j`，切出后缀 `s[j..i-1]`，如果它在字典中，并且前缀 `s[0..j-1]`（即 `dfs(j)`）也能拆分，则 `dfs(i)` 为 true。

**`max_l` 优化**：`ranges::max(w, {}, &string::size).size()` 获取字典中最长单词的长度。切割时子串长度不可能超过 `max_l`，所以 `j` 只需要从 `i-1` 枚举到 `max(0, i - max_l)`，大幅减少循环次数。

**记忆化**：`memo[i]` 存储 `dfs(i)` 的结果，`-1` 表示未计算，避免重复递归。

**递归基**：`i == 0` 时返回 `true`，表示空字符串可以被拆分（是任何合法拆分的起点）。

## 版本二：递推（DP）

翻译成递推：

```cpp
class Solution {
public:
    bool wordBreak(string s, vector<string>& w) {
        int n = s.size();
        unordered_set<string> hash(w.begin(), w.end());
        int max_l = ranges::max(w, {}, &string::size).size();
        vector<int> dp(n + 1, false);
        dp[0] = true;                                      // 空字符串

        for (int i = 1; i <= n; ++i) {
            for (int j = i - 1; j >= max(0, i - max_l); --j) {
                if (dp[j] && hash.contains(s.substr(j, i - j))) {
                    dp[i] = true;
                    break;                                 // 找到一种拆分即可
                }
            }
        }
        return dp[n];
    }
};
```

### 代码分析

**`dp[i]`**：`s[0..i-1]` 能否被拆分。

**初始化**：`dp[0] = true`，空字符串默认可拆分。

**状态转移**：对于每个 `i`，枚举切割点 `j`（`j` 从 `i-1` 往前到 `max(0, i - max_l)`）：

```
dp[i] = dp[j] && s[j..i-1] ∈ wordDict
```

如果 `dp[j]` 为 true（前缀可拆分），且 `s[j..i-1]` 在字典中，则 `dp[i] = true`。

**`break` 剪枝**：一旦找到一种合法拆分，`dp[i]` 就是 true，无需继续枚举。

**`max_l` 优化**：和递归版一样，切出的子串长度不可能超过字典中最长单词的长度，所以 `j` 的下界是 `max(0, i - max_l)`。

以 `s = "catsandog", wordDict = ["cats", "dog", "sand", "and", "cat"]` 为例，`max_l = 4`：

| i | 关键子串 | 结果 | 说明 |
|:---:|:---|:---:|------|
| 0 | — | true | 空字符串 |

| 4 | `"cats"` | true | dp[0]=true, `"cats"` ∈ dict |
| 7 | `"sand"` | true | dp[3]=true, `"sand"` ∈ dict（cat + sand） |
| 7 | `"catsand"` | true | dp[4]=true, `"and"` ∈ dict（cats + and） |

继续到 `i = 9` 时，检查 `s[7..8] = "do"`、`s[6..8] = "ndo"` 等，都不是字典单词。`dp[9]` 始终为 false，最终 `dp[10]` 也为 false。因为 `"og"` 和 `"dog"` 中 `"og"` 不在字典，而 `"dog"` 需要 `dp[6]` 为 true，但 `dp[6]` 为 false（`"catsan"` 无法拆分）。所以返回 `false`。

## 复杂度分析

- **时间复杂度**：O(n · max_l)。外层循环 n 次，内层循环最多 `max_l` 次（字典最长单词长度）。每次 `substr` 和 `hash.contains` 的操作与子串长度有关，但 `max_l ≤ 20`，可视为常数。总复杂度 O(n · max_l)，在 `n ≤ 300`、`max_l ≤ 20` 时非常高效。
- **空间复杂度**：O(n + m)，`dp` 数组 O(n)，哈希表 O(m)（m 为字典单词总字符数）。

## 总结

这道题是 DP 中的"分割型"问题，核心是把字符串切分成前缀和后缀，判断后缀是否在字典中，前缀是否可拆分。

两个版本的递推关系完全一致：

| 版本 | 方向 | 特点 |
|:---|:---|------|
| 递归 + 记忆化 | 自顶向下 | 从 `s.size()` 开始，递归到 0，`memo` 避免重复 |
| 递推（DP） | 自底向上 | 从 0 推到 `s.size()`，`dp` 数组存储中间结果 |

**`max_l` 优化是点睛之笔**：字典中单词最长 20，而 `s` 最长 300，如果不加 `max_l` 限制，内层循环每次扫 300 次，加上 `max_l` 后最多扫 20 次，减少了 90% 以上的无效枚举。

和 279. 完全平方数（完全背包）相比，139 也是"物品无限使用"的问题，但 139 是"是否存在某种组合"（bool DP），279 是"最少需要几个"（min DP），两者都是 DP 的经典应用场景。
