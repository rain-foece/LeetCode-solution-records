# 删除链表的倒数第 N 个结点（Remove Nth Node From End of List）题解

> 题目链接：[LeetCode 19. Remove Nth Node From End of List](https://leetcode.cn/problems/remove-nth-node-from-end-of-list/)

## 题目描述

给你一个链表，删除链表的倒数第 `n` 个结点，并且返回链表的头结点。

**示例 1：**

```
输入：head = [1,2,3,4,5], n = 2
输出：[1,2,3,5]
```

**示例 2：**

```
输入：head = [1], n = 1
输出：[]
```

**示例 3：**

```
输入：head = [1,2], n = 1
输出：[1]
```

---

## 核心思路

这道题的核心难点只有一个：**怎么找到倒数第 n 个节点？**

单链表只能从头往后走，不能倒着走。但我们有一个巧妙的办法——**快慢指针错位法**：

1. 让快指针先走 n 步，此时快慢指针之间恰好相隔 n 个节点。
2. 然后快慢指针同步往前走，当快指针走到链表末尾（`null`）时，慢指针恰好指向倒数第 n 个节点。

为什么？因为快慢指针始终相隔 n 步，当快指针到达终点时，慢指针离终点还有 n 步——也就是倒数第 n 个位置。

**删除操作**：删节点需要知道它的前驱。所以我们用一个 `tmp` 指针始终指向 `slow` 的前一个节点，删除时直接 `tmp->next = slow->next` 即可。

**边界处理**：如果要删除的恰好是头节点怎么办？此时 `slow` 就是 `head`，没有前驱。我们引入一个**哑节点（dummy）**，放在 `head` 前面，`tmp` 初始指向 `dummy`，这样即使删除头节点也能统一处理。

## 代码

```cpp
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    ListNode* removeNthFromEnd(ListNode* head, int n) {
        ListNode *fast = head;

        // 第一步：快指针先走 n 步，拉开差距
        for (int i = 0; i < n; ++i) {
            fast = fast->next;
        }

        ListNode *slow = head;
        ListNode dummy(0, head);          // 哑节点，方便删除头节点
        ListNode *tmp = &dummy;           // tmp 始终指向 slow 的前驱

        // 第二步：快慢指针同步走，直到快指针到末尾
        while (fast) {
            tmp = slow;                   // tmp 跟着 slow 走，保持是 slow 的前驱
            slow = slow->next;
            fast = fast->next;
        }

        // 第三步：删除 slow 指向的节点
        tmp->next = slow->next;

        return dummy.next;                // 返回哑节点的下一个（即真正的头节点）
    }
};
```

## 代码分析

### 为什么快指针先走 n 步就能找到倒数第 n 个？

这是本题最核心的技巧。来看一个直观的图示：

```
链表： 1 → 2 → 3 → 4 → 5 → null，n = 2（删倒数第 2 个，即 4）

第一步：fast 先走 2 步
   slow               fast
    ↓                  ↓
    1 → 2 → 3 → 4 → 5 → null

第二步：fast 和 slow 同步走，直到 fast 到 null
              slow          fast
               ↓             ↓
    1 → 2 → 3 → 4 → 5 → null

slow 指向 4，正是倒数第 2 个！
```

**原理**：快慢指针的间距始终是 n。当快指针走到 `null`（最后一个节点的 `next`）时，慢指针离 `null` 还有 n 步，也就是倒数第 n 个节点。

换个角度想：如果链表总长为 L，fast 先走了 n 步，还剩 L - n 步到末尾。slow 和 fast 同步走 L - n 步后，fast 到达末尾，slow 走了 L - n 步，停在正数第 L - n + 1 个位置，也就是倒数第 n 个。

### 哑节点（dummy）的作用

为什么要引入 `dummy`？考虑边界情况：链表只有 `[1]`，`n = 1`，要删除的就是头节点。

如果没有哑节点，`tmp` 初始指向哪里？没有地方可指。`slow` 就是 `head`，没有前驱，删除操作无法统一处理。

引入哑节点后，链表变成：

```
dummy → 1 → null
```

`tmp` 初始指向 `dummy`，删除 `slow`（即节点 1）时，`tmp->next = slow->next` 把 `dummy` 的 `next` 指向 `null`，然后返回 `dummy.next` 就是空链表，一切统一。

### `tmp` 指针的跟踪方式

注意到 `tmp` 的更新方式：`tmp = slow` 在 `slow` 移动之前执行。这保证了 `tmp` 始终是 `slow` 的前驱。删除时直接 `tmp->next = slow->next`，跳过 `slow` 节点。

## 逐轮推演

以 `head = [1 → 2 → 3 → 4 → 5], n = 2` 为例（删倒数第 2 个，即 4）：

**第一步：fast 先走 n = 2 步**

| 步数 | fast 位置 | 说明 |
|------|----------|------|
| 初始 | 1 | fast = head |
| 1 | 2 | fast = fast->next |
| 2 | 3 | fast = fast->next |

此时状态：`slow = 1, fast = 3, tmp = dummy, dummy.next = 1`

**第二步：fast 和 slow 同步走**

| 轮次 | fast 移动前 | slow 移动前 | tmp 更新 | slow 移动后 | fast 移动后 |
|------|-----------|-----------|---------|-----------|-----------|
| 1 | 3 | 1 | tmp=1 | 2 | 4 |
| 2 | 4 | 2 | tmp=2 | 3 | 5 |
| 3 | 5 | 3 | tmp=3 | 4 | null |

`fast == null`，循环结束。此时 `slow = 4, tmp = 3`。

**第三步：删除**

`tmp->next = slow->next` → `3->next = 5`，节点 4 被跳过。

最终链表：`1 → 2 → 3 → 5`，返回 `dummy.next = 1`。

---

## 复杂度分析

- **时间复杂度**：O(L)，其中 L 是链表长度。fast 先走 n 步，再和 slow 一起走 L - n 步，总共 O(L)。
- **空间复杂度**：O(1)，只用了三个指针。

## 总结

这道题的核心是**快慢指针错位法**找倒数第 n 个节点——快指针先走 n 步拉开间距，再同步走到末尾，慢指针自然落在倒数第 n 个位置。哑节点的引入则优雅地统一了「删除头节点」和「删除非头节点」两种情况。

和 [142. 环形链表 II](142.环形链表II_26_7_23.md) 一样，这道题也是快慢指针的经典应用。区别在于：

| 对比维度 | 19. 删除倒数第 N 个结点 | 142. 环形链表 II |
|---------|----------------------|------------------|
| 快慢指针用法 | 错位法：快指针先走 n 步拉开间距 | 追及法：快指针走两步，慢指针走一步 |
| 目的 | 利用间距定位倒数第 n 个 | 利用速度差检测环并找入环点 |
| 辅助结构 | 哑节点（dummy）统一删除操作 | 无额外节点，纯指针操作 |
| 数学原理 | 间距 = n，快指针到末尾时慢指针即为倒数第 n | a = c + 整圈，两次相遇定位入环点 |

快慢指针在链表题中非常灵活：可以通过**速度差**（142）检测环，也可以通过**间距差**（19）定位位置，本质都是利用两个指针之间的相对关系来获取单链表无法直接得到的信息。
