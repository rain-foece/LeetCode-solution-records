# 矩阵置零（Set Matrix Zeroes）题解

> 题目链接：[LeetCode 73. Set Matrix Zeroes](https://leetcode.cn/problems/set-matrix-zeroes/)

## 题目描述

给定一个 `m × n` 的矩阵，如果一个元素为 0，则将其所在行和列的所有元素都设为 0。请使用原地算法。

**示例 1：**

```
输入：matrix = [[1,1,1],[1,0,1],[1,1,1]]
输出：[[1,0,1],[0,0,0],[1,0,1]]
```

**示例 2：**

```
输入：matrix = [[0,1,2,0],[3,4,5,2],[1,3,1,5]]
输出：[[0,0,0,0],[0,4,5,0],[0,3,1,0]]
```

---

## 核心思路概览

本文将从两个递进的版本展开，将空间复杂度从 O(m + n) 优化到 O(1)：

| 版本 | 方法 | 核心思想 |
|------|------|----------|
| 版本一 | 标记数组 | 用两个 bool 数组记录哪些行、列需要置零 |
| 版本二 | 原地标记 | 用矩阵的第一行和第一列作为标记数组，空间 O(1) |

下面逐一分析。

---

## 版本一：标记数组

### 思路

我们首先能想到遍历，遍历到 0 就把它的行列进行操作不就行了？但上手后却发现不简单——我们经过几次遍历后，未遍历的部分有很多非零元素都变成 0 了，这是我们不想看到的。

但我们发现，只要我们遍历时把需要置零的行列记录下来，然后再整体操作不就行了？所以，我们用 `row` 和 `col` 两个 `bool` 类型数组来记录要置零的行和列。

### 代码

```cpp
class Solution {
public:
    void setZeroes(vector<vector<int>>& matrix) {
        int n = matrix.size();
        int m = matrix[0].size();

        vector<bool> row(n, false);   // row[i] = true 表示第 i 行需要置零
        vector<bool> col(m, false);   // col[j] = true 表示第 j 列需要置零

        // 第一遍：标记哪些行和列有 0
        for (int i = 0; i < n; ++i) {
            for (int j = 0; j < m; ++j) {
                if (matrix[i][j] == 0) {
                    row[i] = true;    // 第 i 行标记
                    col[j] = true;    // 第 j 列标记
                }
            }
        }

        // 第二遍：根据标记置零
        for (int i = 0; i < n; ++i) {
            for (int j = 0; j < m; ++j) {
                if (row[i] || col[j]) {
                    matrix[i][j] = 0; // 行或列被标记，置零
                }
            }
        }
    }
};
```

### 分析

这个版本把「发现零」和「执行置零」拆成了两趟遍历。第一趟只做标记，第二趟只做置零，互不干扰，彻底避免了「边改边产生影响」的问题。

- **时间复杂度**：O(m × n)，两趟遍历。
- **空间复杂度**：O(m + n)，两个标记数组。

**优点**：思路清晰，逻辑简单，是入门理解的好起点。

**缺点**：使用额外空间 O(m + n)。还有办法优化吗？

---

## 版本二：原地标记（用第一行和第一列做标记）

### 思路

时间上肯定是不行了，总要遍历完的。空间呢？我们使用了额外空间，能不能省呢？省下来又放到哪呢？

我们发现，新开辟的数组，正好可以接在原来的矩阵边缘！我们能不能在矩阵中找出一列 + 一行"牺牲"掉做记录呢？这是完全可行的，只要我们在集体操作时豁免这个牺牲行列就行了。

具体做法是：用矩阵的**第一行**来记录每一列是否需要置零，用**第一列**来记录每一行是否需要置零。但这样会覆盖第一行和第一列原本的数据，所以我们需要先用两个布尔变量 `is_first_line` 和 `is_first_row` 单独记录第一行和第一列本身是否需要置零。

### 代码

```cpp
class Solution {
public:
    void setZeroes(vector<vector<int>>& matrix) {
        int n = matrix.size();
        int m = matrix[0].size();

        // 1. 单独记录第一行和第一列是否需要置零
        bool is_first_line = ranges::contains(matrix[0], 0);  // 第一行是否有 0
        bool is_first_row = false;                             // 第一列是否有 0
        for (int i = 0; i < n; ++i) {
            if (matrix[i][0] == 0) {
                is_first_row = true;
                break;
            }
        }

        // 2. 用第一行和第一列作为标记数组
        for (int i = 0; i < n; ++i) {
            for (int j = 0; j < m; ++j) {
                if (matrix[i][j] == 0) {
                    matrix[i][0] = 0;  // 第 i 行有 0 → 记在第一列
                    matrix[0][j] = 0;  // 第 j 列有 0 → 记在第一行
                }
            }
        }

        // 3. 根据标记置零（跳过第一行和第一列，因为它们最后单独处理）
        for (int i = 1; i < n; ++i) {
            for (int j = 1; j < m; ++j) {
                if (matrix[i][0] == 0 || matrix[0][j] == 0) {
                    matrix[i][j] = 0;
                }
            }
        }

        // 4. 最后处理第一行和第一列
        if (is_first_line) {
            for (int i = 0; i < m; ++i) {
                matrix[0][i] = 0;
            }
        }
        if (is_first_row) {
            for (int i = 0; i < n; ++i) {
                matrix[i][0] = 0;
            }
        }
    }
};
```

### 逐轮推演

以 `matrix = [[1,1,1],[1,0,1],[1,1,1]]` 为例，`n = 3, m = 3`：

**步骤 1：记录第一行/列本身的状态**

```
第一行 [1,1,1] → 无 0 → is_first_line = false
第一列 [1,1,1] → 无 0 → is_first_row = false
```

**步骤 2：遍历，用第一行/列做标记**

| i | j | matrix[i][j] | 操作 | matrix 状态 |
|---|---|-------------|------|------------|
| 0 | 0 | 1 | — | |
| 0 | 1 | 1 | — | |
| 0 | 2 | 1 | — | |
| 1 | 0 | 1 | — | |
| 1 | 1 | 0 | matrix[1][0]=0, matrix[0][1]=0 | |
| 1 | 2 | 1 | — | |
| 2 | 0 | 1 | — | |
| 2 | 1 | 1 | — | |
| 2 | 2 | 1 | — | |

标记后矩阵：
```
[1, 0, 1]   ← 第一行第 1 列被标记为 0（意味着第 1 列需要置零）
[0, 0, 1]   ← 第一列第 1 行被标记为 0（意味着第 1 行需要置零）
[1, 1, 1]
```

**步骤 3：根据标记置零（跳过第 0 行和第 0 列）**

| i | j | matrix[i][0] | matrix[0][j] | 操作 | matrix 状态 |
|---|---|-------------|-------------|------|------------|
| 1 | 1 | 0 | 0 | matrix[1][1]=0 | |
| 1 | 2 | 0 | 1 | matrix[1][2]=0 | |
| 2 | 1 | 1 | 0 | matrix[2][1]=0 | |
| 2 | 2 | 1 | 1 | — | |

置零后矩阵：
```
[1, 0, 1]
[0, 0, 0]
[1, 0, 1]
```

**步骤 4：处理第一行/列**

`is_first_line = false, is_first_row = false`，都不需要额外置零。

最终结果：
```
[1, 0, 1]
[0, 0, 0]
[1, 0, 1]
```

---

## 复杂度分析

- **时间复杂度**：O(m × n)，两趟遍历整个矩阵。
- **空间复杂度**：O(1)，只用了两个布尔变量。

---

## 总结

这道题展示了原地算法的经典套路：**把数据本身当作存储结构**。

版本一用额外的 `row` 和 `col` 数组做标记，空间 O(m + n)。版本二更进一步，把第一行和第一列"牺牲"为标记数组，空间降到 O(1)。

理解版本二的关键在于两点：

1. **为什么要单独记录第一行和第一列？** 因为第一行和第一列被用作标记数组，它们自身的数据会被覆盖。如果不提前记录，就不知道它们原本是否需要置零。
2. **为什么置零时要跳过第一行和第一列？** 因为它们的标记角色还没完成。如果提前把它们置零了，后面所有依赖它们的判断都会出错。所以必须在最后一步单独处理。

这种「牺牲一部分空间来标记另一部分」的思路，在矩阵类原地算法中非常常见。
