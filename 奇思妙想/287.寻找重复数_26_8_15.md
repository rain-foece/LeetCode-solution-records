# 寻找重复数（Find the Duplicate Number）题解

> 题目链接：[LeetCode 287. Find the Duplicate Number](https://leetcode.cn/problems/find-the-duplicate-number/)

## 题目描述

给定一个包含 `n + 1` 个整数的数组 `nums`，其数字都在 `[1, n]` 范围内（包括 `1` 和 `n`），可知至少存在一个重复的整数。

假设 `nums` 只有**一个重复的整数**，返回**这个重复的数**。

你设计的解决方案必须**不修改**数组 `nums` 且只用常量级 `O(1)` 的额外空间。

**示例 1：**

```
输入：nums = [1,3,4,2,2]
输出：2
```

**示例 2：**

```
输入：nums = [3,1,3,4,2]
输出：3
```

---

## 核心思路

数字范围 `[1, n]`，数组长度 `n + 1`，天然适合**原地哈希**——把每个数放到它"该在"的位置上（`nums[i]` 放在下标 `nums[i]` 处）。

具体做法：遍历数组，对于位置 `i`，不断把 `nums[i]` 交换到下标 `nums[i]`，直到 `nums[i] == i`。如果在交换过程中发现目标位置已经放好了相同的数（`nums[i] == nums[nums[i]]`），那就是重复数。

---

## 版本一：原地哈希（交换法）

### 代码

```cpp
class Solution {
public:
    int findDuplicate(vector<int>& nums) {
        for (int i = 0; i < nums.size(); ++i) {
            while (nums[i] != i) {
                if (nums[i] == nums[nums[i]]) {
                    return nums[i];
                }
                swap(nums[i], nums[nums[i]]);
            }
        }
        return -1;
    }
};
```

### 代码分析

对于每个位置 `i`：

- 如果 `nums[i] == i`：当前位置已经放了正确的数，跳过。
- 如果 `nums[i] != i`：需要把 `nums[i]` 放到下标 `nums[i]` 处。
  - 先检查目标位置是否已经有了相同的数（`nums[i] == nums[nums[i]]`），如果是，找到了重复数。
  - 否则交换 `nums[i]` 和 `nums[nums[i]]`，继续 while 循环。

### 逐轮推演

以 `nums = [1, 3, 4, 2, 2]` 为例（`n = 4`，数字范围 `[1, 4]`）：

| 轮次 | i | nums | 操作 |
|:---:|:---:|------|------|
| 初始 | — | `[1, 3, 4, 2, 2]` | — |
| 1 | 0 | `[1, 3, 4, 2, 2]` | `nums[0]=1 != 0`，目标 `nums[1]=3`，不等，交换 → |
| 2 | 0 | `[3, 1, 4, 2, 2]` | `nums[0]=3 != 0`，目标 `nums[3]=2`，不等，交换 → |
| 3 | 0 | `[2, 1, 4, 3, 2]` | `nums[0]=2 != 0`，目标 `nums[2]=4`，不等，交换 → |
| 4 | 0 | `[4, 1, 2, 3, 2]` | `nums[0]=4 != 0`，目标 `nums[4]=2`，不等，交换 → |
| 5 | 0 | `[2, 1, 2, 3, 4]` | `nums[0]=2 != 0`，目标 `nums[2]=2`，**相等！** → 返回 2 |

### 复杂度分析

| 指标 | 值 |
|:---|:---|
| 时间复杂度 | O(n) |
| 空间复杂度 | O(1) |

每个数最多被交换一次到达正确位置，总体 O(n)。

> **注意**：原地哈希会修改数组。如果题目严格要求"不修改数组"，请使用下面的版本二。

## 版本二：Floyd 判圈法（快慢指针）

### 核心思路

把数组看作一个链表：`nums[i]` 表示节点 `i` 指向节点 `nums[i]`。因为存在重复数，必有至少两个节点指向同一个节点，形成**环**。

Floyd 判圈法分两步：
1. **快慢指针找相遇点**：`slow = nums[slow]`，`fast = nums[nums[fast]]`，两者相遇时停止。
2. **找环入口**：`slow` 回到起点，两者同步走，再次相遇处即为重复数。

### 代码

```cpp
class Solution {
public:
    int findDuplicate(vector<int>& nums) {
        int slow = 0, fast = 0;
        // 第一步：找相遇点
        do {
            slow = nums[slow];
            fast = nums[nums[fast]];
        } while (slow != fast);
        // 第二步：找环入口
        slow = 0;
        while (slow != fast) {
            slow = nums[slow];
            fast = nums[fast];
        }
        return slow;
    }
};
```

### 代码分析

以 `nums = [1, 3, 4, 2, 2]` 为例：

```
链表视角：0 → 1 → 3 → 2 → 4 → 2 (环)
```

| 步骤 | slow | fast | 说明 |
|:---:|:---:|:---:|------|
| 初始 | 0 | 0 | 都从 0 出发 |
| 1 | 1 | 3 | `slow=nums[0]=1`，`fast=nums[nums[0]]=3` |
| 2 | 3 | 4 | `slow=nums[1]=3`，`fast=nums[nums[3]]=4` |
| 3 | 2 | 4 | `slow=nums[3]=2`，`fast=nums[nums[4]]=4` |
| 4 | 4 | 4 | `slow=nums[2]=4`，`fast=nums[nums[4]]=4` → **相遇** |

相遇后，`slow` 回到 0，`fast` 留在 4，同步走：

| 步骤 | slow | fast |
|:---:|:---:|:---:|
| 1 | 1 | 2 |
| 2 | 3 | 4 |
| 3 | 2 | 2 | → **环入口 = 重复数 = 2** |

### 复杂度分析

| 指标 | 值 |
|:---|:---|
| 时间复杂度 | O(n) |
| 空间复杂度 | O(1) |

不修改数组，严格满足题目要求。

## 总结

| 版本 | 思路 | 修改数组 | 时间 | 空间 |
|:---|------|:---:|:---:|:---:|
| 原地哈希 | 把每个数放到对应下标，发现冲突即返回 | 是 | O(n) | O(1) |
| 快慢指针 | 数组转链表，Floyd 判圈找环入口 | 否 | O(n) | O(1) |

两个版本的核心都是利用了**数字范围 `[1, n]` 与下标 `[0, n]` 的对应关系**：

- 原地哈希：把 `nums[i]` 放到下标 `nums[i]`，冲突即重复
- 快慢指针：把 `nums[i]` 看作 `i → nums[i]` 的边，重复数就是环的入口

快慢指针版本和 142. 环形链表 II 本质上是一道题——数组就是链表，`nums[i]` 就是 `next` 指针。
