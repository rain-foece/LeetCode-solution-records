# 子序列 DP 两种模式：选或不选 vs 枚举选哪个

子序列 DP 问题中，状态转移有两种核心模式。掌握这两种模式，大部分子序列 DP 问题都能迎刃而解。

---

## 一、相邻无关子序列 →「选或不选」

每个元素互相独立，只需依次考虑每个元素**选还是不选**。元素之间的顺序不影响决策，只影响"已选元素集合"。

**状态定义**：`dfs(i, 剩余容量)` — 考虑前 `i` 个元素，剩余容量为 `j`，能否/最优解是什么。

**状态转移**：

```
不选：dfs(i-1, j)
选：  dfs(i-1, j - nums[i]) （容量够的前提下）
```

**典型题目**：

| 题目 | 说明 |
|:---|:---|
| 416. 分割等和子集 | 能否选出和为 sum/2 的子集 |
| 0-1 背包 | 容量限制下最大价值 |
| 494. 目标和 | 添加 +/- 号使和为 target |
| 279. 完全平方数 | 物品无限使用，最少数量 |

**代码模板**（递推）：

```cpp
vector<bool> dp(sum + 1, false);
dp[0] = true;
for (int x : nums) {
    for (int j = sum; j >= x; --j) {   // 倒序遍历（0-1背包）
        dp[j] = dp[j] || dp[j - x];
    }
}
```

---

## 二、相邻相关子序列 →「枚举选哪个」

需要知道子序列中**相邻两个数的关系**（如大小、是否相等）。必须枚举"上一个选的元素是谁"。

**状态定义**：`dfs(i)` — 以第 `i` 个元素**结尾**的最优解。

**状态转移**：

```
dfs(i) = max(dfs(j)) + 1,  j < i 且 nums[j] < nums[i]（以 LIS 为例）
```

**典型题目**：

| 题目 | 相邻关系 |
|:---|:---|
| 300. 最长递增子序列 | `nums[j] < nums[i]` |
| 673. 最长递增子序列的个数 | 同上，额外维护计数 |
| 354. 俄罗斯套娃信封 | 二维递增 |
| 139. 单词拆分 | 前缀是否在字典中 |

**代码模板**（递推，以 LIS 为例）：

```cpp
vector<int> dp(n, 0);
for (int i = 0; i < n; ++i) {
    for (int j = 0; j < i; ++j) {
        if (nums[j] < nums[i]) {
            dp[i] = max(dp[i], dp[j]);
        }
    }
    dp[i]++;
}
return ranges::max(dp);
```

---

## 三、对比总结

| 特征 | 选或不选 | 枚举选哪个 |
|:---|:---|:---|
| **元素关系** | 互相独立，顺序无关 | 相邻相关，需要比大小/判断关系 |
| **状态定义** | `dfs(i, 剩余容量)` | `dfs(i)` = 以 i 结尾的最优解 |
| **递归基** | `i < 0` 时 `j == 0` | `i` 自身为一个子序列（长度 1） |
| **转移方式** | 不选 / 选，两条分支 | 枚举前一个元素 `j`，取最优 |
| **典型复杂度** | O(n · sum) | O(n²) |
| **是否需要排序** | 否 | 元素顺序本身有意义 |
| **典型题** | 416. 分割等和子集、0-1 背包 | 300. 最长递增子序列 |
| **硬要换模式** | — | 需要额外记录上一个选的数的下标，空间 O(n²) |

## 四、两种模式的变体

### 选或不选 + 记忆化

```cpp
auto dfs = [&](this auto&& dfs, int i, int j) -> int {
    if (i < 0) return j == 0 ? 1 : 0;
    int& res = memo[i][j];
    if (res != -1) return res;
    if (j < nums[i]) return res = dfs(i - 1, j);
    return res = dfs(i - 1, j) + dfs(i - 1, j - nums[i]);  // 方案数
};
```

### 枚举选哪个 + 二分优化（LIS 专属）

当只需要长度而不需要具体序列时，LIS 可以用贪心 + 二分优化到 O(n log n)：

```cpp
vector<int> t;
for (int x : nums) {
    auto it = lower_bound(t.begin(), t.end(), x);
    if (it == t.end()) t.push_back(x);
    else *it = x;
}
return t.size();
```

### 枚举选哪个 + 前缀优化（单词拆分）

139. 单词拆分中，`dfs(i)` 枚举切割点 `j`，但用 `max_l` 限制切割长度，实际复杂度 O(n · max_l)：

```cpp
for (int j = i - 1; j >= max(0, i - max_l); --j) {
    if (dp[j] && hash.contains(s.substr(j, i - j))) {
        dp[i] = true;
        break;
    }
}
```

## 五、如何判断用哪种模式？

1. **问自己：元素顺序重要吗？**
   - 不重要（只关心选出哪些元素）→ 选或不选
   - 重要（子序列必须保持原顺序，相邻元素有关系）→ 枚举选哪个

2. **问自己：状态需要记录什么？**
   - 需要记录"还能装多少"（容量、和）→ 选或不选
   - 只需要记录"以谁结尾"→ 枚举选哪个

3. **看题目关键词**：
   - "子集"、"和"、"背包" → 选或不选
   - "子序列"、"递增"、"递减"、"连续" → 枚举选哪个

掌握了这两种模式，大部分子序列 DP 问题都能迎刃而解。
