# K 个一组翻转链表（Reverse Nodes in k-Group）题解

> 题目链接：[LeetCode 25. Reverse Nodes in k-Group](https://leetcode.cn/problems/reverse-nodes-in-k-group/)

## 题目描述

给你链表的头节点 `head`，每 `k` 个节点一组进行翻转，请你返回修改后的链表。

`k` 是一个正整数，它的值小于或等于链表的长度。如果节点总数不是 `k` 的整数倍，那么请将最后剩余的节点保持原有顺序。

你不能只是单纯的改变节点内部的值，而是需要实际进行节点交换。

**示例 1：**

```
输入：head = [1,2,3,4,5], k = 2
输出：[2,1,4,3,5]
```

**示例 2：**

```
输入：head = [1,2,3,4,5], k = 3
输出：[3,2,1,4,5]
```

---

## 核心思路

这道题可以拆成两个子问题：

1. **翻转 k 个节点**：经典的链表翻转，用 `pre`、`cur`、`tmp` 三指针完成。
2. **串联各组**：翻转后，把上一组的尾巴连到当前组的头，当前组的尾巴连到下一组的头。用 `p0` 始终指向「上一组的最后一个节点」。

整体流程：先数一遍节点总数 `n`，然后只要 `n >= k` 就翻转一组，翻完一组后把 `n` 减去 `k`，继续下一组。

## 代码

```cpp
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    ListNode* reverseKGroup(ListNode* head, int k) {
        // 第一步：数节点总数
        int n = 0;
        for (ListNode *p = head; p; p = p->next) ++n;

        ListNode dummy(0, head);          // 哑节点
        ListNode *p0 = &dummy;            // p0：始终指向「上一组的最后一个节点」
        ListNode *pre = nullptr;          // pre：翻转时用，指向前一个节点
        ListNode *cur = head;             // cur：当前要翻转的节点

        for (; n >= k; n -= k) {
            // 第二步：翻转当前组的 k 个节点
            for (int i = 0; i < k; ++i) {
                ListNode *tmp = cur->next; // 暂存下一个
                cur->next = pre;           // 反转指向
                pre = cur;                 // pre 前进
                cur = tmp;                 // cur 前进
            }

            // 第三步：串联翻转后的组
            // 此时 pre 是翻转后的组头，cur 是下一组的第一个节点
            ListNode *tmp = p0->next;      // p0->next 是翻转前的组头（现在是翻转后的组尾）
            p0->next->next = cur;          // 组尾连接到下一组的头
            p0->next = pre;                // 上一组的尾连接到当前组的头
            p0 = tmp;                      // p0 移动到当前组的尾，为下一轮准备
        }

        return dummy.next;
    }
};
```

## 代码分析

### 整体结构

代码分为三块，层层递进，非常清晰：

| 步骤 | 代码块 | 作用 |
|------|--------|------|
| 第一步 | `for (p = head; p; p = p->next) ++n` | 数节点总数，确定有几组需要翻转 |
| 第二步 | 内层 `for (int i = 0; i < k; ++i)` | 翻转当前组的 k 个节点 |
| 第三步 | `p0->next->next = cur; p0->next = pre; p0 = tmp` | 将翻转后的组串联到链表中 |

下面逐一拆解。

### 第一步：统计节点总数

```cpp
int n = 0;
for (ListNode *p = head; p; p = p->next) ++n;
```

很简单，数一遍链表长度。然后用 `n >= k` 作为循环条件，每翻完一组就 `n -= k`，直到剩余不足 `k` 个为止。

### 第二步：翻转 k 个节点（经典链表翻转）

这是所有链表题的基础操作。三个指针 `pre`、`cur`、`tmp`：

```
翻转前：  null ← pre    cur → next → ...
翻转后：  null ← pre ← cur    next → ...
```

每次迭代做四件事：

```
tmp = cur->next    // 1. 暂存下一个节点，防止断链
cur->next = pre    // 2. 反转当前节点的指向
pre = cur          // 3. pre 前进
cur = tmp          // 4. cur 前进
```

翻转 k 次后，`pre` 指向翻转后的组头，`cur` 指向下一组的第一个节点。

### 第三步：串联（最精妙的部分）

翻转后，当前组和前后部分的关系需要重新连接。这里用 `p0` 来维护。

**翻转前的状态：**

```
p0 → [A → B → C] → cur(下一组)
      ↑ 翻转前组头
```

**翻转后（k=3）：**

```
p0 → [A → B → C]  ??  cur(下一组)
                  断裂了！
```

翻转后 `A` 的 `next` 还指向 `B`，`B` 的 `next` 指向 `null`（因为翻转时 `A->next` 被设为了 `null`），`C` 的 `next` 指向 `B`。`pre` 指向 `C`。

此时需要做三次连接：

```
p0->next = pre       →  p0 连接到翻转后的组头 C
p0->next->next = cur →  翻转后的组尾 A 连接到下一组
p0 = tmp             →  p0 移动到组尾 A，为下一轮准备
```

但等等，`p0->next = pre` 执行后，`p0->next` 就变成了 `pre`（即 `C`），不再是 `A` 了。所以我们需要在执行连接之前，先把 `p0->next`（即 `A`）保存下来。

代码中 `ListNode *tmp = p0->next` 就是这个作用——保存翻转前的组头（即翻转后的组尾），供后续使用：

```cpp
ListNode *tmp = p0->next;      // tmp = A（翻转前的组头，翻转后的组尾）
p0->next->next = cur;          // A->next = cur（组尾连下一组）
p0->next = pre;                // p0->next = C（上一组连当前组头）
p0 = tmp;                      // p0 = A（移动到当前组尾）
```

**连接后的状态：**

```
p0 → C → B → A → cur(下一组)
     ↑ 翻转后组头    ↑ 翻转后组尾（p0 现在指向这里）
```

`p0` 现在指向 `A`，即当前组的最后一个节点。下一轮翻转时，`p0` 就是「上一组的尾」，继续连接下一组。

### 哑节点（dummy）的作用

和 [19. 删除链表的倒数第 N 个结点](19.删除链表的倒数第N个结点_26_7_23.md) 一样，`dummy` 放在 `head` 前面，统一处理第一组翻转前后的连接。`p0` 初始指向 `dummy`，第一组翻转后 `p0->next` 就指向了新链表的头。

## 逐轮推演

以 `head = [1 → 2 → 3 → 4 → 5], k = 2` 为例：

**第一步：`n = 5`**

**初始化：**

```
dummy → 1 → 2 → 3 → 4 → 5
p0 = dummy, pre = null, cur = 1
```

---

**第一组翻转（n=5 >= k=2，翻转节点 1→2）：**

| 迭代 | cur | tmp | cur->next | pre | cur | 说明 |
|------|-----|-----|-----------|-----|-----|------|
| 初始 | 1 | — | — | null | 1 | |
| i=0 | 1 | 2 | 1→null | 1 | 2 | 1 指向 null |
| i=1 | 2 | 3 | 2→1 | 2 | 3 | 2 指向 1 |

翻转后：`pre = 2, cur = 3`。翻转结果：`2 → 1 → null`。

**串联：**

```
翻转前：p0(dummy) → 1 → 2 → ...  cur=3
翻转后：pre=2 → 1 → null, cur=3

tmp = p0->next = 1          (翻转后的组尾)
1->next = cur = 3           (组尾连下一组)
p0->next = pre = 2          (dummy 连组头)
p0 = tmp = 1                (p0 移动到组尾)
```

当前链表：`dummy → 2 → 1 → 3 → 4 → 5`，`p0 = 1, n = 3`

---

**第二组翻转（n=3 >= k=2，翻转节点 3→4）：**

`pre = null, cur = 3`

| 迭代 | cur | tmp | cur->next | pre | cur | 说明 |
|------|-----|-----|-----------|-----|-----|------|
| 初始 | 3 | — | — | null | 3 | |
| i=0 | 3 | 4 | 3→null | 3 | 4 | 3 指向 null |
| i=1 | 4 | 5 | 4→3 | 4 | 5 | 4 指向 3 |

翻转后：`pre = 4, cur = 5`。翻转结果：`4 → 3 → null`。

**串联：**

```
翻转前：p0=1 → 3 → 4 → ...  cur=5
翻转后：pre=4 → 3 → null, cur=5

tmp = p0->next = 3          (翻转后的组尾)
3->next = cur = 5           (组尾连下一组)
p0->next = pre = 4          (1 连组头)
p0 = tmp = 3                (p0 移动到组尾)
```

当前链表：`dummy → 2 → 1 → 4 → 3 → 5`，`p0 = 3, n = 1`

---

**剩余处理（n=1 < k=2）：**

不足 k 个，不翻转，直接返回 `dummy.next`。

最终链表：`2 → 1 → 4 → 3 → 5`。

---

## 复杂度分析

- **时间复杂度**：O(n)。第一遍数节点 O(n)，翻转每个节点恰好一次 O(n)，总共 O(n)。
- **空间复杂度**：O(1)。只用了几个指针变量。

## 总结

这道题的难点不在翻转本身（翻转是链表基本功），而在于**串联**——翻转完一组后，如何正确地把它「接回去」。

关键是一句话：**`p0` 始终指向上一组的最后一个节点，用它来连接当前组**。三步串联法的顺序不能乱：

1. 先保存组尾 `tmp = p0->next`（因为 `p0->next` 马上要被覆盖）
2. 组尾连下一组 `p0->next->next = cur`
3. 上一组连当前组头 `p0->next = pre`
4. `p0` 移动到当前组尾 `p0 = tmp`

和 [19. 删除链表的倒数第 N 个结点](19.删除链表的倒数第N个结点_26_7_23.md)、[142. 环形链表 II](142.环形链表II_26_7_23.md) 一样，这道题也大量使用了哑节点（dummy）来统一边界处理。链表题中，哑节点几乎是一个「标配」——当你需要操作头节点时，它能让所有节点的处理逻辑保持一致。
