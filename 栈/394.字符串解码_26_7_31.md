# 字符串解码（Decode String）题解

> 题目链接：[LeetCode 394. Decode String](https://leetcode.cn/problems/decode-string/)

## 题目描述

给定一个经过编码的字符串，返回它解码后的字符串。

编码规则为：`k[encoded_string]`，表示其中方括号内部的 `encoded_string` 正好重复 `k` 次。注意 `k` 保证为正整数。

你可以认为输入字符串总是有效的；输入字符串中没有额外的空格，且输入的方括号总是符合格式要求的。

此外，你可以认为原始数据不包含数字，所有的数字只表示重复的次数 `k`，例如不会出现像 `3a` 或 `2[4]` 的输入。

**示例 1：**

```
输入：s = "3[a]2[bc]"
输出："aaabcbc"
```

**示例 2：**

```
输入：s = "3[a2[c]]"
输出："accaccacc"
```

**示例 3：**

```
输入：s = "2[abc]3[cd]ef"
输出："abcabccdcdcdef"
```

---

## 核心思路

这道题的根源还是括号匹配，只不过在匹配的同时要加入字符串拼接。

嵌套的 `k[encoded_string]` 天然具有"后进先出"的结构——最内层的括号最先被解码，然后逐层向外。这和栈完美匹配。

具体做法：栈中每个元素是一个 `pair{重复次数, 已累积字符串}`。每当遇到 `[` 时，新开一层（压入新 pair），把这一层的重复次数和空字符串存进去；遇到 `]` 时，当前层结束，弹出并重复拼接后追加到上一层。

栈底放一个 `{1, ""}` 作为哨兵，保证最终结果直接取自栈顶，也确保 `]` 弹出后总有上一层可以追加。

## 代码

```cpp
class Solution {
public:
    string decodeString(string s) {
        stack<pair<int, string>> stk;
        stk.push({1, ""});                     // 栈底哨兵

        for (int i = 0; i < s.size(); ++i) {
            // 情况一：遇到数字 → 解析完整数字，压入新层
            if (isdigit(s[i])) {
                int count = 0;
                while (i < s.size() && isdigit(s[i])) {
                    count = count * 10 + (s[i] - '0');
                    ++i;
                }
                // 此时 s[i] 一定是 '['，压入新层
                stk.push({count, ""});
                // 注意：循环外 for 的 ++i 还会执行，这里不用再 ++i
                continue;
            }

            // 情况二：遇到字母 → 追加到当前层
            if (s[i] >= 'a' && s[i] <= 'z') {
                stk.top().second += s[i];
            }

            // 情况三：遇到 ']' → 当前层结束，弹出并重复拼接到上一层
            if (s[i] == ']') {
                auto [cnt, str] = stk.top();
                stk.pop();
                for (int j = 0; j < cnt; ++j) {
                    stk.top().second += str;
                }
            }
        }

        return stk.top().second;
    }
};
```

## 代码分析

### 栈结构与哨兵

```cpp
stack<pair<int, string>> stk;
stk.push({1, ""});
```

每个栈帧代表一层嵌套：

- `first`（int）：当前层的重复次数 `k`
- `second`（string）：当前层已累积的字符串

栈底哨兵 `{1, ""}` 的作用：
- 最外层没有显式的 `k[`，它相当于最外层的"虚拟层"，重复次数为 1。
- 遇到 `]` 弹出时，保证总有上一层来接收拼接结果。
- 最终答案直接取 `stk.top().second`，无需额外处理。

### 情况一：解析数字

```cpp
if (isdigit(s[i])) {
    int count = 0;
    while (i < s.size() && isdigit(s[i])) {
        count = count * 10 + (s[i] - '0');
        ++i;
    }
    stk.push({count, ""});
    continue;
}
```

数字可能有多位（如 `32[a]`），所以用循环逐位解析。`count * 10 + (s[i] - '0')` 是经典的字符串转整数写法。

解析完数字后，`s[i]` 一定指向 `[`。此时压入新栈帧 `{count, ""}`，表示进入新的一层。注意 `continue` 后 `for` 循环的 `++i` 会跳过 `[`，让下一轮直接处理 `[` 之后的内容。

### 情况二：追加字母

```cpp
if (s[i] >= 'a' && s[i] <= 'z') {
    stk.top().second += s[i];
}
```

字母直接追加到当前栈帧的字符串中。无论字母出现在 `[` 之前还是之后，它都属于当前层。

### 情况三：遇到 `]`

```cpp
if (s[i] == ']') {
    auto [cnt, str] = stk.top();
    stk.pop();
    for (int j = 0; j < cnt; ++j) {
        stk.top().second += str;
    }
}
```

当前层结束：
1. 取出栈顶的 `{cnt, str}`，`cnt` 是重复次数，`str` 是这一层累积的字符串。
2. 弹出栈顶，回到上一层。
3. 将 `str` 重复 `cnt` 次，追加到上一层的字符串中。

这里用 C++17 结构化绑定 `auto [cnt, str] = stk.top()` 拆解 pair，代码更清晰。

## 逐轮推演

以 `s = "3[a2[c]]"` 为例：

| 轮次 | i | 字符 | 栈（顶→底） | 操作 |
|:---:|:---:|:---:|:---|------|
| 初始 | — | — | `{1, ""}` | 哨兵入栈 |
| 1 | 0 | `3` | `{1, ""}`, `{3, ""}` | 解析数字 3，压入新层 |
| 2 | 2 | `a` | `{1, ""}`, `{3, "a"}` | 追加到当前层 |
| 3 | 3 | `2` | `{1, ""}`, `{3, "a"}`, `{2, ""}` | 解析数字 2，压入新层 |
| 4 | 5 | `c` | `{1, ""}`, `{3, "a"}`, `{2, "c"}` | 追加到当前层 |
| 5 | 6 | `]` | `{1, ""}`, `{3, "acc"}` | 弹出 `{2, "c"}`，重复 2 次 → `"cc"`，追加到上一层 |
| 6 | 7 | `]` | `{1, "accaccacc"}` | 弹出 `{3, "acc"}`，重复 3 次 → `"accaccacc"`，追加到哨兵 |

返回 `"accaccacc"`。

---

再以 `s = "2[abc]3[cd]ef"` 为例：

| 轮次 | 字符 | 栈（顶→底） | 操作 |
|:---:|:---:|:---|------|
| 初始 | — | `{1, ""}` | 哨兵 |
| 1 | `2` | `{1, ""}`, `{2, ""}` | 解析数字 2，压入新层 |
| 2 | `a,b,c` | `{1, ""}`, `{2, "abc"}` | 逐字追加 |
| 3 | `]` | `{1, "abcabc"}` | 弹出，重复 2 次，追加到哨兵 |
| 4 | `3` | `{1, "abcabc"}`, `{3, ""}` | 解析数字 3，压入新层 |
| 5 | `c,d` | `{1, "abcabc"}`, `{3, "cd"}` | 追加 |
| 6 | `]` | `{1, "abcabccdcdcd"}` | 弹出，重复 3 次，追加到哨兵 |
| 7 | `e,f` | `{1, "abcabccdcdcdef"}` | 追加到哨兵 |

返回 `"abcabccdcdcdef"`。

## 复杂度分析

- **时间复杂度**：O(S)，其中 S 是解码后字符串的长度。每个字符在栈中只被组装一次，`]` 时的重复拼接虽然是循环，但总共拼接的字符数就是输出长度。
- **空间复杂度**：O(S)，栈中存储的字符串总长度与输出长度成正比。嵌套深度最多与输入长度同阶。

---

## 总结

这道题从括号匹配出发，在栈的基础上加了一层"字符串累积"。核心设计是：

1. **每个栈帧 = 一层嵌套**：`{重复次数, 累积字符串}`，`[` 时压入，`]` 时弹出并重复拼接。
2. **栈底哨兵** `{1, ""}` 统一了最外层和嵌套层的处理逻辑。
3. **数字解析**用 `while (isdigit)` 循环支持多位数，`continue` 配合 `for` 的 `++i` 自然跳过 `[`。

和 20. 有效的括号（纯匹配）相比，394 多了"把匹配到的内容重复拼接"这一步，但栈的用法本质相同——都是利用后进先出处理嵌套结构。
