# 有效的括号（Valid Parentheses）题解

> 题目链接：[LeetCode 20. Valid Parentheses](https://leetcode.cn/problems/valid-parentheses/)

## 题目描述

给定一个只包括 `'('`，`')'`，`'{'`，`'}'`，`'['`，`']'` 的字符串 `s`，判断字符串是否有效。

有效字符串需满足：

1. 左括号必须用相同类型的右括号闭合。
2. 左括号必须以正确的顺序闭合。
3. 每个右括号都有一个对应的相同类型的左括号。

**示例 1：**

```
输入：s = "()"
输出：true
```

**示例 2：**

```
输入：s = "()[]{}"
输出：true
```

**示例 3：**

```
输入：s = "(]"
输出：false
```

**示例 4：**

```
输入：s = "([])"
输出：true
```

---

## 核心思路

括号匹配是栈的经典应用。"后进先出"恰好对应括号的"最近未匹配的左括号必须先闭合"这一规则。

遍历字符串：
- 遇到**左括号**：压入栈中，等待匹配。
- 遇到**右括号**：检查栈顶是否是对应的左括号。是则弹出，不是或栈为空则无效。

遍历结束后，栈为空说明所有左括号都被正确匹配了，否则无效。

---

## 代码

```cpp
class Solution {
public:
    bool isValid(string s) {
        stack<char> st;
        for (int i = 0; i < s.size(); ++i) {
            // 左括号 → 入栈
            if (s[i] == '(' || s[i] == '[' || s[i] == '{') {
                st.push(s[i]);
                continue;
            }
            // 右括号 → 检查栈顶
            else {
                if (st.empty()) return false;          // 栈空，无左括号可匹配
                char c = st.top();
                if (c == '(' && s[i] == ')' ||
                    c == '[' && s[i] == ']' ||
                    c == '{' && s[i] == '}')
                    st.pop();                          // 匹配成功，弹出
                else
                    return false;                      // 类型不匹配
            }
        }
        return st.empty();                             // 栈空才有效
    }
};
```

---

## 代码分析

### 左括号处理

```cpp
if (s[i] == '(' || s[i] == '[' || s[i] == '{') {
    st.push(s[i]);
    continue;
}
```

遇到任意左括号，直接入栈。`continue` 跳过后续的右括号逻辑，让代码结构更清晰——左括号和右括号的分支互不干扰。

### 右括号处理

```cpp
else {
    if (st.empty()) return false;
    char c = st.top();
    if (c == '(' && s[i] == ')' ||
        c == '[' && s[i] == ']' ||
        c == '{' && s[i] == '}')
        st.pop();
    else
        return false;
}
```

分三步判断：

1. **栈为空**：当前右括号没有对应的左括号，直接返回 `false`。例如 `s = "]"` 或 `s = "())"`。
2. **类型匹配**：栈顶左括号与当前右括号配对，弹出栈顶，继续遍历。
3. **类型不匹配**：例如栈顶是 `'('` 但当前字符是 `']'`，返回 `false`。

### 最终检查

```cpp
return st.empty();
```

遍历结束后，栈必须为空。非空说明有多余的左括号没有匹配，例如 `s = "(()"`，遍历完栈中还有一个 `'('`。

## 逐轮推演

以 `s = "([])"` 为例：

| 轮次 | 字符 | 栈（顶→底） | 操作 |
|:---:|:---:|:---|------|
| 初始 | — | 空 | — |
| 1 | `(` | `(` | 左括号，入栈 |
| 2 | `[` | `[` `(` | 左括号，入栈 |
| 3 | `]` | `(` | 右括号，栈顶 `[` 匹配，弹出 |
| 4 | `)` | 空 | 右括号，栈顶 `(` 匹配，弹出 |

遍历结束，栈为空，返回 `true`。

---

以 `s = "(])"` 为例：

| 轮次 | 字符 | 栈（顶→底） | 操作 |
|:---:|:---:|:---|------|
| 1 | `(` | `(` | 左括号，入栈 |
| 2 | `]` | `(` | 右括号，栈顶 `(` 与 `]` 不匹配 → 返回 `false` |

---

## 复杂度分析

- **时间复杂度**：O(n)，每个字符入栈/出栈各最多一次。
- **空间复杂度**：O(n)，最坏情况下全是左括号，栈中保存 n 个字符。

---

## 总结

括号匹配是栈最经典的入门题，核心就一句话：**左括号入栈，右括号弹栈匹配**。两个关键检查点：

1. 右括号出现时栈不能为空（否则没左括号可匹配）。
2. 遍历结束后栈必须为空（否则有多余左括号没匹配）。

这道题的思路也适用于其他"最近匹配"场景，比如 HTML 标签闭合检查、表达式求值中的括号处理等。
