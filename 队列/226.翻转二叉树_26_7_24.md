# 翻转二叉树（Invert Binary Tree）题解

> 题目链接：[LeetCode 226. Invert Binary Tree](https://leetcode.cn/problems/invert-binary-tree/)

## 题目描述

给你一棵二叉树的根节点 `root`，翻转这棵二叉树，并返回其根节点。

**示例 1：**

```
输入：root = [4,2,7,1,3,6,9]
输出：[4,7,2,9,6,3,1]
```

**示例 2：**

```
输入：root = [2,1,3]
输出：[2,3,1]
```

---

## 核心思路

翻转二叉树，本质上就是**把每个节点的左右子树交换位置**。这个操作天然适合用 DFS（深度优先遍历）来实现——一路向下，先处理完子节点，再交换回来。

为什么用栈？因为 DFS 的核心是**后进先出**。我们先把根节点压栈，然后每次弹出一个节点，交换它的左右子树，再把它非空的子节点压栈。栈保证了我们先深入处理某一棵子树，直到叶子再回溯。

## 代码

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    TreeNode* invertTree(TreeNode* root) {
        if (!root) return nullptr;

        stack<TreeNode*> stack;
        stack.push(root);

        while (!stack.empty()) {
            TreeNode *tmp = stack.top();
            stack.pop();

            // 交换当前节点的左右子树
            swap(tmp->left, tmp->right);

            // 把非空子节点压栈（先左后右，但因为是栈所以实际先处理右）
            if (tmp->left) stack.push(tmp->left);
            if (tmp->right) stack.push(tmp->right);
        }

        return root;
    }
};
```

## 代码分析

### 为什么用栈？

栈的核心特性是**后进先出（LIFO）**，这恰好对应了 DFS 的`深入到底再回溯`。

```
压栈顺序：root → left → right
弹栈顺序：right → left → ...

所以算法会沿着左子树一路深入到底，再回溯处理右子树
```

如果你把栈换成队列，代码依然能跑，但遍历顺序就变成了 BFS（层序遍历）。这就是栈和队列的本质区别——栈实现 DFS，队列实现 BFS。详见 [101. 对称二叉树](101.对称二叉树_26_7_24.md) 的队列解法。

### 压栈顺序有讲究吗？

没有。先压左还是先压右，只影响 DFS 是先走左子树还是先走右子树，不影响最终结果——因为每个节点终归都会被访问到，而翻转操作 `swap` 和访问顺序无关。

### 和递归的关系

递归本质上也是用**系统调用栈**来实现 DFS。这个迭代版本只是把递归隐式的系统栈，换成了显式的 `stack` 数据结构。两者在逻辑上完全等价：

| 递归 | 迭代（栈） |
|------|----------|
| 函数调用压系统栈 | `stack.push()` |
| 函数返回弹系统栈 | `stack.pop()` |
| 隐式，编译器管理 | 显式，自己控制 |

## 逐轮推演

以 `root = [4,2,7,1,3,6,9]` 为例：

```
初始：
        4
      /   \
     2     7
    / \   / \
   1   3 6   9
```

| 步骤 | 栈状态 | 弹出 | 操作 | 压入 | 说明 |
|------|--------|------|------|------|------|
| 1 | `[4]` | 4 | swap(2,7) | 2,7 | 4 的左右交换 |
| 2 | `[2,7]` | 7 | swap(6,9) | 6,9 | 7 的左右交换 |
| 3 | `[2,6,9]` | 9 | — | — | 9 无子节点 |
| 4 | `[2,6]` | 6 | — | — | 6 无子节点 |
| 5 | `[2]` | 2 | swap(1,3) | 1,3 | 2 的左右交换 |
| 6 | `[1,3]` | 3 | — | — | 3 无子节点 |
| 7 | `[1]` | 1 | — | — | 1 无子节点 |
| 8 | `[]` | — | — | — | 结束 |

```
最终：
        4
      /   \
     7     2
    / \   / \
   9   6 3   1
```

## 复杂度分析

- **时间复杂度**：O(n)，每个节点被访问恰好一次。
- **空间复杂度**：O(h)，h 为树的高度。栈中最多存储一条从根到叶子的路径上的节点数。最坏情况（链状树）O(n)，最好情况（完全平衡树）O(log n)。

---

## 总结

翻转二叉树是 DFS + 栈的入门题。核心操作只有两步：弹出节点 → 交换其左右子树 → 把子节点压栈。整个过程就是一次 DFS 遍历，在遍历过程中顺手完成翻转。

这道题和 [101. 对称二叉树](101.对称二叉树_26_7_24.md) 形成了鲜明的 DFS vs BFS 对比——一个用栈（深入优先），一个用队列（广度优先），是理解两种遍历范式的最佳切入点。
