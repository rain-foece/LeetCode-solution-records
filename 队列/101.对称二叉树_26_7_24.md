# 对称二叉树（Symmetric Tree）题解

> 题目链接：[LeetCode 101. Symmetric Tree](https://leetcode.cn/problems/symmetric-tree/)

## 题目描述

给你一个二叉树的根节点 `root`，检查它是否轴对称。

**示例 1：**

```
输入：root = [1,2,2,3,4,4,3]
输出：true
```

**示例 2：**

```
输入：root = [1,2,2,null,3,null,3]
输出：false
```

---

## 核心思路

判断一棵树是否轴对称，本质上是**逐层比较左右两棵子树是否互为镜像**。

这个任务天然适合用 BFS（广度优先遍历）来实现——因为对称性是按层体现的，我们需要一层一层地比较。用队列来存储待比较的节点对，每次从队首取出一对节点进行比较，然后把它们的子节点按镜像顺序入队。

为什么用队列？因为 BFS 的核心是**先进先出**。队列保证了我们按层处理——先比较完当前层的所有节点对，再进入下一层。

## 代码

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    bool isSymmetric(TreeNode* root) {
        deque<TreeNode*> q;

        // 初始：把根节点的左右子树作为第一对比较对象
        q.push_back(root->left);
        q.push_back(root->right);

        while (!q.empty()) {
            // 每次取出一对节点进行比较
            TreeNode *u = q.front(); q.pop_front();
            TreeNode *v = q.front(); q.pop_front();

            // 两个都为空，这一对没问题，继续
            if (!u && !v) continue;

            // 一个为空一个不为空，或者值不相等 → 不对称
            if ((!u || !v) || (u->val != v->val)) return false;

            // 按镜像顺序入队：u的左 对 v的右，v的左 对 u的右
            q.push_back(u->left);
            q.push_back(v->right);
            q.push_back(v->left);
            q.push_back(u->right);
        }

        return true;
    }
};
```

## 代码分析

### 为什么用队列？

队列的核心特性是**先进先出（FIFO）**，这恰好对应了 BFS 的`逐层推进`。

```
入队顺序：a, b, c, d, ...
出队顺序：a, b, c, d, ...

所以算法会按层处理——先把当前层的所有节点对比较完，再进入下一层
```

如果你把队列换成栈，代码依然能跑，但遍历顺序就变成了 DFS。详见 [226. 翻转二叉树](226.翻转二叉树_26_7_24.md) 的栈解法。

### 镜像入队顺序

这是本题最核心的细节。比较完一对节点 `(u, v)` 后，需要把它们的子节点按镜像关系入队：

```
u 的左子树  ↔  v 的右子树   （镜像对称）
v 的左子树  ↔  u 的右子树   （镜像对称）
```

所以入队顺序是：

```cpp
q.push_back(u->left);   // ①
q.push_back(v->right);  // ②  ①和②是一对
q.push_back(v->left);   // ③
q.push_back(u->right);  // ④  ③和④是一对
```

下一轮循环中，`pop_front` 会依次取出 (①, ②) 和 (③, ④) 进行比较，恰好是镜像位置。

### 空节点的处理

```cpp
if (!u && !v) continue;                    // 两边都空 → 这一对没问题
if ((!u || !v) || (u->val != v->val))      // 一空一不空 或 值不等 → 不对称
    return false;
```

注意，即使 `u` 和 `v` 都是空节点，它们的"子节点"不存在，不需要入队。`continue` 直接跳过，不会把空指针的 `left`/`right` 入队。

### 用 `deque` 而不是 `queue`

代码中用了 `deque`（双端队列）而不是 `queue`。`deque` 支持 `push_back` 和 `pop_front`，功能上和 `queue` 等价，但 `deque` 在 C++ 中可以直接作为队列使用，写法更灵活。

## 逐轮推演

以 `root = [1,2,2,3,4,4,3]` 为例：

```
        1
      /   \
     2     2
    / \   / \
   3   4 4   3
```

| 轮次 | 队首取出 | 比较结果 | 操作 | 入队后队列 |
|------|---------|---------|------|-----------|
| 初始 | — | — | 入队(2, 2) | `[2, 2]` |
| 1 | (2, 2) | 值相等 ✓ | 入队(3, 3), (4, 4) | `[3, 3, 4, 4]` |
| 2 | (3, 3) | 值相等 ✓ | 都是叶子，无子节点入队 | `[4, 4]` |
| 3 | (4, 4) | 值相等 ✓ | 都是叶子，无子节点入队 | `[]` |

队列为空，返回 `true`。

---

再以 `root = [1,2,2,null,3,null,3]` 为例：

```
        1
      /   \
     2     2
      \     \
       3     3
```

| 轮次 | 队首取出 | 比较结果 | 操作 | 入队后队列 |
|------|---------|---------|------|-----------|
| 初始 | — | — | 入队(2, 2) | `[2, 2]` |
| 1 | (2, 2) | 值相等 ✓ | 入队(null, 3), (3, null) | `[null, 3, 3, null]` |
| 2 | (null, 3) | 一空一不空 ✗ | 返回 false | — |

返回 `false`。

## DFS vs BFS 对比

这两道题恰好是 DFS 和 BFS 的教科书级对比：

| 对比维度 | 226. 翻转二叉树 | 101. 对称二叉树 |
|---------|---------------|----------------|
| 数据结构 | 栈（stack） | 队列（deque） |
| 遍历方式 | DFS（深度优先） | BFS（广度优先） |
| 核心操作 | 每次弹出一个节点 | 每次弹出一对节点 |
| 处理顺序 | 先深入子树，再回溯 | 按层推进，逐层比较 |
| 子节点入队 | 随意，不影响结果 | 必须按镜像顺序 |
| 空节点处理 | 不入栈 | 入队参与比较 |
| 本质 | 遍历 + 操作 | 逐对比较 |

两道题代码结构几乎一样：

```cpp
// 226: 栈 + DFS
while (!stack.empty()) {
    弹出节点;
    交换左右;
    压入子节点;
}

// 101: 队列 + BFS
while (!q.empty()) {
    弹出一对节点;
    比较;
    按镜像顺序入队子节点;
}
```

唯一的区别就是把 `stack` 换成了 `queue`，把「弹出一个节点」换成了「弹出一对节点」，遍历顺序就从 DFS 变成了 BFS。

## 复杂度分析

- **时间复杂度**：O(n)，每个节点被访问恰好一次。
- **空间复杂度**：O(n)，队列中最多存储一层节点数。最坏情况（完全二叉树的最底层）约 n/2 个节点。

---

## 总结

判断对称二叉树是 BFS + 队列的经典题。核心操作是：每次取出一对节点比较 → 按镜像顺序把子节点对入队 → 继续下一对。整个过程就是一次 BFS，在逐层推进的过程中完成对称性校验。

这道题和 [226. 翻转二叉树](226.翻转二叉树_26_7_24.md) 形成了鲜明的 DFS vs BFS 对比——将 `stack` 换成 `queue`，遍历顺序就从「深入优先」变成了「广度优先」。理解这两道题，就理解了栈和队列在树遍历中的本质区别。
