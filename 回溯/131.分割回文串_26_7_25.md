# 分割回文串（Palindrome Partitioning）题解

> 题目链接：[LeetCode 131. Palindrome Partitioning](https://leetcode.cn/problems/palindrome-partitioning/)

## 题目描述

给你一个字符串 `s`，请你将 `s` 分割成一些子串，使每个子串都是**回文串**。返回 `s` 所有可能的分割方案。

**示例 1：**

```
输入：s = "aab"
输出：[["a","a","b"],["aa","b"]]
```

**示例 2：**

```
输入：s = "a"
输出：[["a"]]
```

---

## 核心思路

这道题是典型的**回溯 + 分割**问题。和 [46. 全排列](46.全排列_26_7_25.md) 不同，全排列是「选数字」，而这道题是「选分割点」。

核心思路：从字符串的某个位置 `i` 出发，枚举所有可能的**结束位置 `j`**，如果子串 `s[i..j]` 是回文串，就把它加入当前分割方案，然后递归处理剩余部分 `s[j+1..]`。递归到底（`i == n`）时，收获一个完整的分割方案。

本质上，这就是在字符串的每个空隙处决定「切还是不切」，但用回溯的方式高效地枚举了所有可能。

---

## 代码

```cpp
class Solution {
    // 判断子串 s[left..right] 是否为回文串（双指针向中收缩）
    bool is(string &s, int left, int right) {
        while (left < right) {
            if (s[left++] != s[right--]) return false;
        }
        return true;
    }

public:
    vector<vector<string>> partition(string s) {
        int n = s.size();
        vector<vector<string>> ans;
        vector<string> tmp;                    // 当前分割方案

        auto dfs = [&](this auto&& dfs, int i) {
            if (i == n) {                      // 已经处理完整个字符串
                ans.push_back(tmp);            // 收获当前方案
                return;
            }

            // 枚举从 i 开始的所有可能子串
            for (int j = i; j < n; ++j) {
                if (is(s, i, j)) {             // s[i..j] 是回文串
                    tmp.push_back(s.substr(i, j - i + 1));  // 加入方案
                    dfs(j + 1);                // 递归处理剩余部分
                    tmp.pop_back();            // 回溯，撤销选择
                }
            }
        };

        dfs(0);
        return ans;
    }
};
```

## 代码分析

### 回文串判断：双指针向中收缩

```cpp
bool is(string &s, int left, int right) {
    while (left < right) {
        if (s[left++] != s[right--]) return false;
    }
    return true;
}
```

这是最经典的回文串判断方法——左右指针同时向中间移动，逐字符比较。时间复杂度 O(len)，`len` 是子串长度。

> 注意：这里没有提前做预处理（如 DP 预计算所有子串是否为回文），因为回溯过程中每个子串只判断一次，直接双指针足够。如果题目要求优化，可以用 DP 预处理把 `is` 降到 O(1)，但代码会复杂不少。

### 回溯框架：分割问题的标准模板

```cpp
auto dfs = [&](this auto&& dfs, int i) {
    if (i == n) {           // 递归出口：处理完整个字符串
        ans.push_back(tmp);
        return;
    }

    for (int j = i; j < n; ++j) {   // 枚举子串结束位置
        if (is(s, i, j)) {           // 剪枝：只有回文串才继续
            tmp.push_back(...);      // 做出选择
            dfs(j + 1);              // 递归
            tmp.pop_back();          // 撤销选择
        }
    }
};
```

这个结构和全排列的版本一几乎一样，只是把「选数字」换成了「选子串」：

| 对比维度 | 46. 全排列 | 131. 分割回文串 |
|---------|-----------|---------------|
| 枚举什么 | 选哪个数字填入当前位置 | 选子串的结束位置 |
| 剪枝条件 | `!on_path[j]`（不能重复选） | `is(s, i, j)`（必须是回文串） |
| 递归参数 | `i + 1`（填下一个位置） | `j + 1`（处理剩余字符串） |
| 回溯操作 | `on_path[j] = false` | `tmp.pop_back()` |

### 为什么是 `dfs(j + 1)` 而不是 `dfs(i + 1)`？

这是分割类回溯最容易出错的地方。`i` 是当前子串的**起点**，`j` 是**终点**。当前子串 `s[i..j]` 已经处理完了，下一次递归应该从 `j + 1` 开始，即跳过已处理的部分。

如果写成 `dfs(i + 1)`，那就变成每次只切一个字符，永远无法跳过中间部分，永远得不到 `["aa", "b"]` 这样的方案。

### `substr` 的参数

```cpp
s.substr(i, j - i + 1)
```

`substr(pos, len)`：从 `pos` 开始，取 `len` 个字符。子串 `[i, j]` 的长度是 `j - i + 1`。

## 逐轮推演

以 `s = "aab"` 为例，`n = 3`：

```
                   dfs(0)
                 /        \
          j=0: "a"✓     j=1: "aa"✓
           dfs(1)         dfs(2)
          /      \           \
   j=1:"a"✓   j=2:"ab"✗   j=2:"b"✓
    dfs(2)      剪枝!       dfs(3)
      |                       |
  j=2:"b"✓                 i==n
   dfs(3)                收获! ["aa","b"]
     |
   i==n
 收获! ["a","a","b"]
```

**详细步骤：**

| 步骤 | i | j | 子串 | 回文? | 操作 | tmp 状态 |
|------|---|---|------|-------|------|----------|
| 1 | 0 | 0 | `"a"` | ✓ | push, dfs(1) | `["a"]` |
| 2 | 1 | 1 | `"a"` | ✓ | push, dfs(2) | `["a","a"]` |
| 3 | 2 | 2 | `"b"` | ✓ | push, dfs(3) | `["a","a","b"]` |
| 4 | — | — | i=3==n | — | 收获方案！ | `["a","a","b"]` |
| 5 | 2 | — | — | — | pop 回溯 | `["a","a"]` |
| 6 | 1 | — | — | — | pop 回溯 | `["a"]` |
| 7 | 0 | 1 | `"aa"` | ✓ | push, dfs(2) | `["a","aa"]` |
| 8 | 2 | 2 | `"b"` | ✓ | push, dfs(3) | `["aa","b"]` |
| 9 | — | — | i=3==n | — | 收获方案！ | `["aa","b"]` |
| 10 | 2 | — | — | — | pop 回溯 | `["aa"]` |
| 11 | 0 | 2 | `"aab"` | ✗ | 剪枝，跳过 | `[]` |

最终 `ans = [["a","a","b"], ["aa","b"]]`。

## 复杂度分析

- **时间复杂度**：O(n × 2^n)。最坏情况下（如 `s = "aaa...a"`，每个子串都是回文），每个位置都可以选择「切」或「不切」，共有 2^(n-1) 种分割方案。每种方案需要 O(n) 时间复制到结果中。
- **空间复杂度**：O(n)。递归栈深度 + `tmp` 数组大小。

## 总结

这道题是回溯在**字符串分割**场景下的经典应用。核心框架和全排列一模一样——枚举选择 → 剪枝 → 递归 → 回溯，只是「选择」从「数字」变成了「子串结束位置」。

和 [46. 全排列](46.全排列_26_7_25.md) 对比，可以发现回溯题的套路非常统一：

| 要素 | 46. 全排列 | 131. 分割回文串 |
|------|-----------|---------------|
| 枚举范围 | 所有未选的数字 | 从 i 开始的所有子串 |
| 选择操作 | `path[i] = nums[j]` | `tmp.push_back(substr)` |
| 剪枝条件 | 已被选过 | 不是回文串 |
| 递归参数 | `i + 1`（下一位置） | `j + 1`（跳过已处理） |
| 回溯操作 | 恢复标记 | `pop_back` |

理解回溯，只需要记住一句话：**做出选择 → 递归 → 撤销选择**。不同的题只是「选择」的定义不同而已。
