# N 皇后（N-Queens）题解

> 题目链接：[LeetCode 51. N-Queens](https://leetcode.cn/problems/n-queens/)

## 题目描述

按照国际象棋的规则，皇后可以攻击与之处在同一行或同一列或同一斜线上的棋子。

**n 皇后问题**研究的是如何将 `n` 个皇后放置在 `n × n` 的棋盘上，并且使皇后彼此之间不能相互攻击。

给你一个整数 `n`，返回所有不同的 n 皇后问题的解决方案。

每一种解法包含一个不同的 n 皇后问题的棋子放置方案，该方案中 `'Q'` 和 `'.'` 分别代表了皇后和空位。

**示例 1：**

```
输入：n = 4
输出：[[".Q..","...Q","Q...","..Q."],["..Q.","Q...","...Q",".Q.."]]
解释：如上图所示，4 皇后问题存在两个不同的解法。
```

**示例 2：**

```
输入：n = 1
输出：[["Q"]]
```

---

## 核心思路

经典的回溯 + 剪枝问题。我们逐行放置皇后——每行尝试在某一列放一个皇后，放置后检查是否与之前行的皇后冲突，不冲突就递归到下一行。

关键问题只有两个：

1. **如何判断当前位置能否放置皇后？** — 这就是 `Canplace` 函数的核心，需要检查三个方向：同一列、左斜线、右斜线。
2. **回溯框架** — 逐行尝试每列，能放就递归，不能就回溯换下一列。

## 代码

```cpp
class Solution {
    // 判断在 (row, col) 放置皇后是否合法
    bool Canplace(vector<string>& tmp, int row, int col) {
        for (int i = 0; i < row; ++i) {
            if (tmp[i][col] == 'Q' ||                              // 同列
                col >= row - i && tmp[i][col - row + i] == 'Q' ||  // 左斜线
                col + row - i < tmp.size() && tmp[i][col + row - i] == 'Q') // 右斜线
                return false;
        }
        return true;
    }

public:
    vector<vector<string>> solveNQueens(int n) {
        vector<string> tmp(n, string(n, '.'));     // 当前棋盘
        vector<vector<string>> ans;

        auto dfs = [&](this auto&& dfs, int k) -> void {
            if (k == n) {                          // 所有行都放置完毕
                ans.emplace_back(tmp);
                return;
            }

            for (int t = 0; t < n; ++t) {          // 尝试当前行的每一列
                tmp[k][t] = 'Q';                   // 放置皇后
                if (Canplace(tmp, k, t))
                    dfs(k + 1);                    // 合法，递归下一行
                tmp[k][t] = '.';                   // 回溯，撤销皇后
            }
        };

        dfs(0);
        return ans;
    }
};
```

## 代码分析

### Canplace 函数：三方向检查

这是本题最核心的部分。由于我们是**逐行**放置皇后，当前行 `row` 之后还没有皇后，所以只需要检查 `[0, row-1]` 行中是否有冲突。

皇后能攻击的方向有三个：**同列**、**左斜线（\）**、**右斜线（/）**。同行不需要检查，因为我们每行只放一个。

```cpp
bool Canplace(vector<string>& tmp, int row, int col) {
    for (int i = 0; i < row; ++i) {              // 只检查之前已放置的行
        if (tmp[i][col] == 'Q' ||                 // ① 同列冲突
            col >= row - i &&                     // ② 左斜线边界检查
            tmp[i][col - row + i] == 'Q' ||       // ③ 左斜线冲突
            col + row - i < tmp.size() &&         // ④ 右斜线边界检查
            tmp[i][col + row - i] == 'Q')         // ⑤ 右斜线冲突
            return false;
    }
    return true;
}
```

#### ① 同列检查：`tmp[i][col] == 'Q'`

最简单，第 `i` 行第 `col` 列是否有皇后。

#### ②③ 左斜线（\）检查

左斜线是指从左上到右下的对角线。在左斜线上，**所有格子的「行号 - 列号」是常数**：

```
     列0  列1  列2  列3
行0  \   .   .   .     行0-列0 = 0
行1  .   \   .   .     行1-列1 = 0
行2  .   .   \   .     行2-列2 = 0
行3  .   .   .   \     行3-列3 = 0

同一条 \ 上：row - col = 常数
```

假设之前第 `i` 行有一个皇后在左斜线上，它所在的列是 `oldCol`。因为它和 `(row, col)` 在同一个左斜线上：

```
i - oldCol = row - col
⇒ oldCol = col - row + i
```

所以我们要检查 `tmp[i][col - row + i]` 是否为 `'Q'`。

但 `col - row + i` 可能越界（小于 0），所以需要 `col >= row - i` 做边界保护。这个条件等价于 `col - row + i >= 0`。

#### ④⑤ 右斜线（/）检查

右斜线是指从右上到左下的对角线。在右斜线上，**所有格子的「行号 + 列号」是常数**：

```
     列0  列1  列2  列3
行0  .   .   .   /     行0+列3 = 3
行1  .   .   /   .     行1+列2 = 3
行2  .   /   .   .     行2+列1 = 3
行3  /   .   .   .     行3+列0 = 3

同一条 / 上：row + col = 常数
```

同理，之前第 `i` 行的皇后在 `oldCol`，和 `(row, col)` 在同一右斜线上：

```
i + oldCol = row + col
⇒ oldCol = col + row - i
```

所以检查 `tmp[i][col + row - i]` 是否为 `'Q'`。同样需要边界保护 `col + row - i < n`。

### 三种冲突方向总结

| 方向 | 常量特征 | 旧列号公式 | 边界保护 |
|------|---------|-----------|---------|
| 同列 | `col = 常数` | `col`（不变） | 无需 |
| 左斜线 `\` | `row - col = 常数` | `col - row + i` | `col >= row - i` |
| 右斜线 `/` | `row + col = 常数` | `col + row - i` | `col + row - i < n` |

### 回溯部分

```cpp
auto dfs = [&](this auto&& dfs, int k) -> void {
    if (k == n) {
        ans.emplace_back(tmp);
        return;
    }
    for (int t = 0; t < n; ++t) {
        tmp[k][t] = 'Q';           // 放置
        if (Canplace(tmp, k, t))
            dfs(k + 1);            // 合法，进入下一行
        tmp[k][t] = '.';           // 回溯
    }
};
```

回溯框架和 [46. 全排列](46.全排列_26_7_25.md)、[131. 分割回文串](131.分割回文串_26_7_25.md) 完全一致：**做出选择 → 检查合法性 → 递归 → 撤销选择**。

区别在于 N 皇后的「选择」是某行某列，且**先放置再检查**（`tmp[k][t] = 'Q'` 在前，`Canplace` 在后），因为这个函数本身需要读取 `tmp` 中已放置的皇后来判断。

## 逐轮推演

以 `n = 4` 为例，展示找到第一个解的过程：

```
初始：全部为 '.'
....
....
....
....

k=0（第0行）：
  t=0: (0,0)放Q → Canplace ✓ → dfs(1)
    k=1（第1行）：
      t=0: (1,0)放Q → Canplace ✗（同列）
      t=1: (1,1)放Q → Canplace ✗（左斜线）
      t=2: (1,2)放Q → Canplace ✓ → dfs(2)
        k=2（第2行）：
          t=0: (2,0)放Q → Canplace ✗（同列）
          t=1: (2,1)放Q → Canplace ✗（右斜线）
          t=2: (2,2)放Q → Canplace ✗（同列）
          t=3: (2,3)放Q → Canplace ✗（左斜线）
          全失败，回溯
      t=3: (1,3)放Q → Canplace ✓ → dfs(2)
        k=2（第2行）：
          t=0: (2,0)放Q → Canplace ✗（同列）
          t=1: (2,1)放Q → Canplace ✓ → dfs(3)
            k=3（第3行）：
              t=0: (3,0)放Q → Canplace ✗（同列）
              t=1: (3,1)放Q → Canplace ✗（同列）
              t=2: (3,2)放Q → Canplace ✓ → dfs(4) → 收获！
              方案：[".Q..","...Q","Q...","..Q."]
```

回溯树非常庞大，DFS 做了大量剪枝才找到可行解。

## 复杂度分析

- **时间复杂度**：O(n!)。第一行有 n 种选择，第二行大约 n-2 种（剪枝后），近似 n!。虽然剪枝大幅减少了实际搜索量，但理论上界仍是 O(n!)。
- **空间复杂度**：O(n)。递归栈深度为 n，`tmp` 占用 O(n²) 但这是输出所需的空间。

## 总结

N 皇后是回溯算法的经典例题。核心在于 `Canplace` 函数——利用对角线的数学性质（`row - col = 常数`、`row + col = 常数`），用两行公式算出旧列号，一行代码完成三条线的冲突检查。

和 [46. 全排列](46.全排列_26_7_25.md)、[131. 分割回文串](131.分割回文串_26_7_25.md) 一样，回溯的框架始终如一：

| 要素 | 46. 全排列 | 131. 分割回文串 | 51. N 皇后 |
|------|-----------|---------------|-----------|
| 枚举什么 | 选哪个数字 | 子串结束位置 | 当前行放哪列 |
| 合法性检查 | 数字未被选过 | 子串是回文 | 三方向无冲突 |
| 递归参数 | `i + 1`（下一位置） | `j + 1`（跳过已处理） | `k + 1`（下一行） |
| 回溯操作 | 恢复标记 | `pop_back` | 置回 `'.'` |

理解回溯，只需记住六个字：**选择 → 递归 → 撤销**。
