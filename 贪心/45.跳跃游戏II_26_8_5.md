# 跳跃游戏 II（Jump Game II）题解

> 题目链接：[LeetCode 45. Jump Game II](https://leetcode.cn/problems/jump-game-ii/)

## 题目描述

给定一个长度为 `n` 的 **0 索引**整数数组 `nums`。初始位置在下标 `0`。

每个元素 `nums[i]` 表示从索引 `i` 向后跳转的最大长度。换句话说，如果你在索引 `i` 处，你可以跳转到任意 `(i + j)` 处：

- `0 <= j <= nums[i]` 且
- `i + j < n`

返回到达 `n - 1` 的**最小跳跃次数**。测试用例保证可以到达 `n - 1`。

**示例 1：**

```
输入：nums = [2,3,1,1,4]
输出：2
解释：跳到最后一个位置的最小跳跃数是 2。
     从下标 0 跳到下标 1，跳 1 步，然后跳 3 步到达数组的最后一个位置。
```

**示例 2：**

```
输入：nums = [2,3,0,1,4]
输出：2
```

---

## 核心思路

这道题是 55. 跳跃游戏的升级版——55 只问"能不能到"，45 问"最少跳几步"。

我们可以把数组看作一个隐式的图：位置 `i` 可以一步跳到 `[i+1, i+nums[i]]` 中的任意位置。问题转化为从起点 `0` 到终点 `n-1` 的最短路径，BFS 天然适合。

但不需要显式建图。用两个变量模拟 BFS 的"层"：

- **`len`**：当前步数 `step` 能到达的最远位置（当前层的右边界）。
- **`mlen`**：下一步能到达的最远位置（下一层的右边界）。

遍历数组时，每个位置 `i` 都在当前层内，不断用 `i + nums[i]` 更新 `mlen`。当 `i` 走到 `len`（当前层尽头）时，说明当前层探索完毕，步数 +1，进入下一层。

---

## 代码

```cpp
class Solution {
public:
    int jump(vector<int>& nums) {
        int step = 0;          // 已跳步数
        int len = 0;           // 当前步数能到达的最远位置
        int mlen = 0;          // 下一步能到达的最远位置

        for (int i = 0; i < nums.size() - 1; ++i) {
            // 如果当前层已经能覆盖终点，直接返回
            if (len >= nums.size() - 1) return step;

            // 用当前位置更新"下一步最远距离"
            mlen = max(mlen, i + nums[i]);

            // 走到当前层尽头 → 步数+1，进入下一层
            if (i == len) {
                ++step;
                len = mlen;
            }
        }
        return step;
    }
};
```

## 代码分析

### 三个变量

```cpp
int step = 0;    // 已跳步数
int len = 0;     // 当前步数能到达的最远位置
int mlen = 0;    // 下一步能到达的最远位置
```

把到达过程想象成 BFS 的"一层一层"推进：

```
第 0 步：只能站在位置 0，len = 0
第 1 步：从位置 0 出发，能跳到的最远位置，len = mlen₁
第 2 步：从第 1 步能到的所有位置出发，能跳到的最远位置，len = mlen₂
...
```

`len` 始终是当前层的右边界，`mlen` 是正在探索中的下一层右边界。

### 遍历逻辑

```cpp
for (int i = 0; i < nums.size() - 1; ++i) {
    if (len >= nums.size() - 1) return step;
    mlen = max(mlen, i + nums[i]);
    if (i == len) {
        ++step;
        len = mlen;
    }
}
```

**为什么遍历到 `n-2` 而不是 `n-1`？** 因为到达最后一个位置不需要再跳了。如果 `len` 提前覆盖了终点，直接返回步数。

**`mlen = max(mlen, i + nums[i])`**：当前位置 `i` 能跳到的所有位置中，取最远的那个，更新下一层的边界。

**`if (i == len)`**：当 `i` 走到当前层的最右边界时，说明当前层所有位置都探索完了。此时：
- 步数 +1（`++step`）。
- 进入下一层（`len = mlen`）。

### 提前返回

```cpp
if (len >= nums.size() - 1) return step;
```

每轮开始先检查：当前层是否已经覆盖终点？如果是，当前步数就是答案，无需继续遍历。这个优化在"能提前到达"的用例中减少不必要的循环。

## 逐轮推演

以 `nums = [2, 3, 1, 1, 4]` 为例：

| 轮次 | i | len（当前层边界） | mlen（下一层边界） | i == len? | step | 说明 |
|:---:|:---:|:---:|:---:|:---:|:---:|------|
| 初始 | — | 0 | 0 | — | 0 | 起点 |
| 1 | 0 | 0 | 0+2=2 | i=0 == len=0 ✓ | 1 | 走完第 0 层，步数+1，len=2 |
| 2 | 1 | 2 | 1+3=4 | 1 ≠ 2 | 1 | 更新 mlen=4 |
| 3 | 2 | 2 | 2+1=3 | i=2 == len=2 ✓ | 2 | 走完第 1 层，步数+1，len=4 |

`len = 4 ≥ n-1 = 4`，下一轮循环开头就会返回 `step = 2`。

**分层可视化**：

```
nums:  [2,  3,  1,  1,  4]
        0   1   2   3   4

第 0 步：位置 [0]                     len=0
第 1 步：位置 [1, 2]    ← 从 0 跳来   len=2
第 2 步：位置 [3, 4]    ← 从 1,2 跳来  len=4 ≥ n-1，停止
```

最少 2 步。

---

以 `nums = [2, 3, 0, 1, 4]` 为例：

| 轮次 | i | len | mlen | i == len? | step | 说明 |
|:---:|:---:|:---:|:---:|:---:|:---:|------|
| 初始 | — | 0 | 0 | — | 0 | — |
| 1 | 0 | 0 | 2 | i=0 == len=0 ✓ | 1 | len=2 |
| 2 | 1 | 2 | 4 | 1 ≠ 2 | 1 | mlen=4 |
| 3 | 2 | 2 | 4 | i=2 == len=2 ✓ | 2 | len=4 |

`len = 4 ≥ n-1 = 4`，返回 `step = 2`。

**分层可视化**：

```
nums:  [2,  3,  0,  1,  4]
        0   1   2   3   4

第 0 步：位置 [0]                     len=0
第 1 步：位置 [1, 2]    ← 从 0 跳来   len=2
第 2 步：位置 [3, 4]    ← 从 1 跳来   len=4 ≥ n-1
```

注意位置 2 的 `nums[2] = 0`，跳不动，但位置 1 的 `nums[1] = 3` 直接覆盖了 3 和 4，所以不影响结果。

## 复杂度分析

- **时间复杂度**：O(n)，每个位置访问一次。
- **空间复杂度**：O(1)，只用了三个变量。

## 总结

这道题是 55. 跳跃游戏的升级版，核心思想仍然是贪心，但多了一层"分层"的概念：

1. **`len`** 是当前步数能到达的最远位置（当前层边界）。
2. **`mlen`** 是正在探索的下一层最远位置。
3. 当 `i` 走到 `len` 时，步数 +1，进入下一层。

本质上是**隐式 BFS**——每个位置 `i` 能跳到的范围 `[i+1, i+nums[i]]` 是它指向的"邻居"，`len` 和 `mlen` 模拟了 BFS 的队列分层。和 55 相比，55 只关心最远距离（`m`），45 需要知道"第几步到达最远"，所以多了一个分层变量 `len`。
