# 买卖股票的最佳时机（Best Time to Buy and Sell Stock）题解

> 题目链接：[LeetCode 121. Best Time to Buy and Sell Stock](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock/)

## 题目描述

给定一个数组 `prices`，它的第 `i` 个元素 `prices[i]` 表示一支给定股票第 `i` 天的价格。

你只能选择**某一天**买入这只股票，并选择在**未来的某一个不同的日子**卖出该股票。设计一个算法来计算你所能获取的最大利润。

返回你可以从这笔交易中获取的最大利润。如果你不能获取任何利润，返回 `0`。

注意只能一次买一次卖。

**示例 1：**

```
输入：[7,1,5,3,6,4]
输出：5
解释：在第 2 天（股票价格 = 1）的时候买入，在第 5 天（股票价格 = 6）的时候卖出，最大利润 = 6-1 = 5。
     注意利润不能是 7-1 = 6, 因为卖出价格需要大于买入价格；同时，你不能在买入前卖出股票。
```

**示例 2：**

```
输入：prices = [7,6,4,3,1]
输出：0
解释：在这种情况下, 没有交易完成, 所以最大利润为 0。
```

## 核心思路

这道题是贪心思想的启蒙题。

只能买卖一次，意味着我们需要在历史最低点买入，在之后的最高点卖出。遍历价格数组时，维护两个变量：

- **`min_price`**：到当前位置为止的最低价格（最佳买入点）。
- **`ans`**：到当前位置为止的最大利润（当前价格 - 历史最低价的最大值）。

每到一个新价格，先算"如果今天卖出能赚多少"（`p - min_price`），更新答案；再检查今天是否是最低点，如果是则更新 `min_price`。这样一次遍历就能得到答案——因为我们只关心**到今天为止的最低买入价**，不需要知道未来。

为什么是贪心？因为每一步我们都在做"当前最优"的选择：用迄今为止的最低价格作为买入价，计算当前能获得的最大利润。而这个局部最优最终通向全局最优——真正的最低点之后出现的最高点，就是全局最大利润。

## 代码

```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int n = prices.size(), ans = 0;
        int min_price = INT_MAX / 2;          // 历史最低价，初始化为极大值

        for (int& p : prices) {
            ans = max(ans, p - min_price);    // 如果今天卖出，能赚多少？
            if (p < min_price)                // 今天是否是最低点？
                min_price = p;
        }
        return ans;
    }
};
```

---

## 代码分析

### 初始化

```cpp
int min_price = INT_MAX / 2;
```

`INT_MAX / 2` 而不是 `INT_MAX`，是为了防止 `p - min_price` 时整数溢出。虽然本题 prices 值不会大到溢出，但这是一个好习惯。

### 遍历逻辑

```cpp
for (int& p : prices) {
    ans = max(ans, p - min_price);
    if (p < min_price) min_price = p;
}
```

两行代码，顺序很关键：

1. **先算利润**：`p - min_price` 是以历史最低价买入、今天卖出的利润。用 `max` 更新全局最大利润。
2. **再更新最低价**：如果今天价格比历史最低还低，更新 `min_price`。

**为什么先算利润，后更新最低价？** 因为同一天不能既买又卖。如果今天是最低价，那今天卖出的利润应该是 0（买入价 = 卖出价），而不是负数。先算利润保证了 `p - min_price` 中的 `min_price` 一定是**今天之前**的最低点，符合"卖出日在买入日之后"的约束。

## 逐轮推演

以 `prices = [7, 1, 5, 3, 6, 4]` 为例：

| 轮次 | p | min_price（更新前） | p - min_price | ans | 更新 min_price? |
|:---:|:---:|:---:|:---:|:---:|:---:|
| 初始 | — | INT_MAX/2 | — | 0 | — |
| 1 | 7 | INT_MAX/2 | 负 | 0 | 7 < INT_MAX/2 → min_price=7 |
| 2 | 1 | 7 | 1-7=-6 | 0 | 1 < 7 → min_price=1 |
| 3 | 5 | 1 | 5-1=4 | 4 | 5 > 1，不更新 |
| 4 | 3 | 1 | 3-1=2 | 4 | 3 > 1，不更新 |
| 5 | 6 | 1 | 6-1=5 | 5 | 6 > 1，不更新 |
| 6 | 4 | 1 | 4-1=3 | 5 | 4 > 1，不更新 |

最终 `ans = 5`，即在价格为 1 时买入、价格为 6 时卖出。

---

以 `prices = [7, 6, 4, 3, 1]`（一路下跌）为例：

| 轮次 | p | min_price（更新前） | p - min_price | ans | 更新 min_price? |
|:---:|:---:|:---:|:---:|:---:|:---:|
| 初始 | — | INT_MAX/2 | — | 0 | — |
| 1 | 7 | INT_MAX/2 | 负 | 0 | min_price=7 |
| 2 | 6 | 7 | -1 | 0 | min_price=6 |
| 3 | 4 | 6 | -2 | 0 | min_price=4 |
| 4 | 3 | 4 | -1 | 0 | min_price=3 |
| 5 | 1 | 3 | -2 | 0 | min_price=1 |

最终 `ans = 0`，一路下跌，没有利润可赚。

## 复杂度分析

- **时间复杂度**：O(n)，一次遍历。
- **空间复杂度**：O(1)，只用了两个变量。

## 总结

这道题是贪心思想的入门题，核心就一句话：**遍历过程中，用历史最低价作为买入价，每一天算一次"如果今天卖出"的利润，取最大值**。

两行代码的顺序（先算利润、后更新最低价）是关键——保证了买入价一定来自今天之前，不会犯"同一天买卖"的错误。

和 122. 买卖股票的最佳时机 II（可多次买卖，累加所有上涨段）相比，121 只能买卖一次，所以不需要处理"多次交易"的复杂状态，贪心逻辑更纯粹。
