# 跳跃游戏（Jump Game）题解

> 题目链接：[LeetCode 55. Jump Game](https://leetcode.cn/problems/jump-game/)

## 题目描述

给你一个非负整数数组 `nums`，你最初位于数组的**第一个下标**。数组中的每个元素代表你在该位置可以跳跃的最大长度。

判断你是否能够到达最后一个下标，如果可以，返回 `true`；否则，返回 `false`。

**示例 1：**

```
输入：nums = [2,3,1,1,4]
输出：true
解释：可以先跳 1 步，从下标 0 到达下标 1, 然后再从下标 1 跳 3 步到达最后一个下标。
```

**示例 2：**

```
输入：nums = [3,2,1,0,4]
输出：false
解释：无论怎样，总会到达下标为 3 的位置。但该下标的最大跳跃长度是 0，所以永远不可能到达最后一个下标。
```

---

## 核心思路

这道题不需要关心"具体怎么跳"，只需要关心"最远能跳到哪"。

维护一个变量 `m`，表示当前能到达的**最远下标**。从起点出发，逐个位置推进：只要当前位置 `i` 在可达范围内（`i <= m`），就用 `i + nums[i]` 更新最远距离。如果最终 `m >= n-1`，说明能到达终点。

为什么是贪心？因为每一步我们都取"当前能跳到的最远位置"，而这个局部最优直接决定了全局可达性——如果最远距离都覆盖不了终点，那无论如何都到不了。

---

## 代码

```cpp
class Solution {
public:
    bool canJump(vector<int>& nums) {
        int m = 0, n = nums.size();
        int i = 0;

        // 只要当前位置可达，就尝试向前推进
        while (i <= m && i < n) {
            m = max(m, i + nums[i]);   // 更新最远可达距离
            ++i;
        }

        return m >= n - 1 ? true : false;
    }
};
```

---

## 代码分析

### 变量含义

- `m`：当前能到达的最远下标。
- `i`：当前所在位置。
- 循环条件 `i <= m && i < n`：`i <= m` 确保当前位置可达（如果 `i > m`，说明当前位置跳不到，后续位置更跳不到）；`i < n` 防止越界。

### 循环逻辑

```cpp
while (i <= m && i < n) {
    m = max(m, i + nums[i]);
    ++i;
}
```

每一步，从位置 `i` 出发最多能跳到 `i + nums[i]`。用 `max` 更新最远距离 `m`，然后 `i` 向前推进一格。

**关键点**：当 `i` 超过 `m` 时循环终止。此时有两种情况：
- `m >= n-1`：最远距离覆盖了终点 → `true`。
- `m < n-1`：卡在某个位置无法前进 → `false`。

### 返回值

```cpp
return m >= n - 1 ? true : false;
```

等价于 `return m >= n - 1;`。如果最远可达距离 ≥ 最后一个下标，说明能到达。

---

## 逐轮推演

以 `nums = [2, 3, 1, 1, 4]` 为例：

| 轮次 | i | i ≤ m? | nums[i] | i + nums[i] | m（更新后） | m ≥ n-1? |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| 初始 | 0 | — | — | — | 0 | — |
| 1 | 0 | 0 ≤ 0 ✓ | 2 | 0+2=2 | 2 | 2 < 4 |
| 2 | 1 | 1 ≤ 2 ✓ | 3 | 1+3=4 | 4 | 4 ≥ 4 → 后续可提前退出 |

`m = 4 ≥ n-1 = 4`，返回 `true`。

---

以 `nums = [3, 2, 1, 0, 4]` 为例：

| 轮次 | i | i ≤ m? | nums[i] | i + nums[i] | m（更新后） | m ≥ n-1? |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| 初始 | 0 | — | — | — | 0 | — |
| 1 | 0 | 0 ≤ 0 ✓ | 3 | 0+3=3 | 3 | 3 < 4 |
| 2 | 1 | 1 ≤ 3 ✓ | 2 | 1+2=3 | 3 | 3 < 4 |
| 3 | 2 | 2 ≤ 3 ✓ | 1 | 2+1=3 | 3 | 3 < 4 |
| 4 | 3 | 3 ≤ 3 ✓ | 0 | 3+0=3 | 3 | 3 < 4 |
| 5 | 4 | 4 ≤ 3 ✗ | — | — | 循环终止 | — |

循环终止时 `i = 4, m = 3`，`m < n-1`，返回 `false`。位置 3 的跳跃长度为 0，卡住了，无法到达位置 4。

---

## 复杂度分析

- **时间复杂度**：O(n)，每个位置最多访问一次。
- **空间复杂度**：O(1)，只用了两个变量。

---

## 总结

这道题是贪心思想的典型应用，核心就一句话：**不关心怎么跳，只关心最远能跳到哪**。

一个变量 `m` 维护最远可达距离，一路推进、一路更新。循环条件 `i <= m` 保证了只探索真正可达的位置——一旦 `i > m`，说明前面已经"断粮"了，后续位置都不可能到达。

和 121. 买卖股票的最佳时机（维护历史最低价）一样，55 也是用 O(1) 额外空间维护一个"最值"来驱动贪心决策。两者的共同点是：局部最优（每一步跳到最远 / 每一天用最低价算利润）直接通向全局最优。
