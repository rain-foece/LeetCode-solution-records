# 数组中的第K个最大元素（Kth Largest Element in an Array）题解

> 题目链接：[LeetCode 215. Kth Largest Element in an Array](https://leetcode.cn/problems/kth-largest-element-in-an-array/)

## 题目描述

给定整数数组 `nums` 和整数 `k`，请返回数组中第 `k` 个最大的元素。

请注意，你需要找的是数组排序后的第 `k` 个最大的元素，而不是第 `k` 个不同的元素。

你必须设计并实现时间复杂度为 O(n) 的算法解决此问题。

**示例 1：**

```
输入: [3,2,1,5,6,4], k = 2
输出: 5
```

**示例 2：**

```
输入: [3,2,3,1,2,4,5,5,6], k = 4
输出: 4
```

---

## 核心思路

这道题算是快速排序的启蒙题。

要找**第 k 大**，等价于找排序后下标为 `n - k` 的元素（第 `n - k` 小）。快速排序的核心操作是 partition：选一个基准值（pivot），将数组划分为"小于 pivot"和"大于 pivot"两部分。如果 pivot 恰好落在目标位置 `n - k`，答案就找到了；否则根据 pivot 的位置，只在左半边或右半边继续找——这就是**快速选择（Quickselect）**算法。

下面给出两种实现：版本一用额外数组做三路划分，直观易懂；版本二用原地 partition，空间更优。

---

## 版本一：三路划分（额外数组）

```cpp
class Solution {
public:
    int findKthLargest(vector<int>& nums, int k) {
        int dummy = nums[rand() % nums.size()];   // 随机选 pivot
        vector<int> big, small, equal;

        for (int num : nums) {
            if (num < dummy)
                small.push_back(num);
            else if (num > dummy)
                big.push_back(num);
            else
                equal.push_back(num);
        }

        // 第 k 大 → 在 big 中
        if (k <= big.size())
            return findKthLargest(big, k);

        // 第 k 大 → 在 small 中
        else if (k > nums.size() - small.size())
            return findKthLargest(small, k - nums.size() + small.size());

        // 第 k 大 → 就是 dummy
        else
            return dummy;
    }
};
```

### 代码分析

**三路划分**：将数组分成三个桶：
- `big`：大于 pivot 的元素
- `equal`：等于 pivot 的元素
- `small`：小于 pivot 的元素

**递归决策**：根据 `k` 与各部分大小的关系，决定在哪一路继续搜：

```
   [ big ]  [ equal ]  [ small ]
   ← bsize → ← esize → ← ssize →
```

- `k <= bsize`：第 k 大在 `big` 中，递归搜 `big`。
- `k > bsize + esize`：第 k 大在 `small` 中。注意 `k` 要换算：`k' = k - (n - ssize) = k - n + ssize`。
- 否则：第 k 大就是 `dummy` 本身。

条件 `k > nums.size() - small.size()` 等价于 `k > bsize + esize`，即排除了 big 和 equal 后，目标落入 small。

**随机 pivot**：`rand() % nums.size()` 随机选基准，避免最坏情况（每次选到最小/最大元素导致 O(n²)）。期望时间复杂度 O(n)。

## 版本二：原地 partition

```cpp
class Solution {
    int part(int left, int j, vector<int>& nums) {
        // 随机选 pivot，换到最左边
        int i = left + rand() % (j - left + 1);
        int dummy = nums[i];
        swap(nums[i], nums[left]);

        i = left + 1;
        while (1) {
            // 从左找第一个 ≥ dummy 的
            while (i <= j && nums[i] < dummy)
                ++i;
            // 从右找第一个 ≤ dummy 的
            while (i <= j && nums[j] > dummy)
                --j;
            if (i >= j)
                break;
            swap(nums[i], nums[j]);
            ++i;
            --j;
        }
        // 将 pivot 放到正确位置
        swap(nums[left], nums[j]);
        return j;   // pivot 最终位置
    }

public:
    int findKthLargest(vector<int>& nums, int k) {
        srand(time(NULL));
        int n = nums.size(), l = 0, r = n - 1;
        int target = n - k;   // 第 k 大 = 第 target 小

        while (1) {
            int tmp = part(l, r, nums);
            if (tmp == target)
                return nums[tmp];
            else if (tmp < target)
                l = tmp + 1;        // 目标在右边
            else
                r = tmp - 1;        // 目标在左边
        }
    }
};
```

### 代码分析

**`part` 函数**：在 `[left, right]` 范围内做一次 partition，返回 pivot 最终位置。

1. 随机选一个 pivot，交换到 `nums[left]` 位置。
2. `i` 从左向右扫描，找第一个 `≥ pivot` 的元素；`j` 从右向左扫描，找第一个 `≤ pivot` 的元素。
3. 交换 `nums[i]` 和 `nums[j]`，然后 `i++`、`j--`。
4. 当 `i >= j` 时，所有元素已分好，将 pivot 放到 `j` 位置，返回 `j`。

**主循环**：`target = n - k` 是排序后目标元素的下标。每次 partition 后：
- `tmp == target`：找到了，直接返回。
- `tmp < target`：目标在 pivot 右边，缩小范围到 `[tmp+1, r]`。
- `tmp > target`：目标在 pivot 左边，缩小范围到 `[l, tmp-1]`。

**对比版本一**：版本二原地操作，无额外数组开销，但 partition 逻辑更复杂。版本一代码更短，但每次递归都创建新数组，空间 O(n)。

## 逐轮推演

以 `nums = [3, 2, 1, 5, 6, 4], k = 2` 为例，使用版本二。`target = 6 - 2 = 4`。

**第一轮 partition**：`l = 0, r = 5`，随机选 pivot（假设选中 `nums[0] = 3`）：

```
初始: [3, 2, 1, 5, 6, 4]   pivot=3 换到最左
       i=1, j=5

i=1: nums[1]=2 < 3 → i++
i=2: nums[2]=1 < 3 → i++
i=3: nums[3]=5 ≥ 3 → 停

j=5: nums[5]=4 > 3 → j--
j=4: nums[4]=6 > 3 → j--
j=3: nums[3]=5 > 3 → j--
j=2: nums[2]=1 ≤ 3 → 停

i=3, j=2 → i≥j，退出循环
swap(nums[0], nums[2]) → [1, 2, 3, 5, 6, 4]
返回 tmp=2
```

`tmp = 2 < target = 4`，目标在右边，`l = 3, r = 5`。

**第二轮 partition**：`l = 3, r = 5`，随机选 pivot（假设选中 `nums[4] = 6`）：

```
当前: [1, 2, 3, 5, 6, 4]   pivot=6 换到最左
swap(nums[4], nums[3]) → [1, 2, 3, 6, 5, 4]
       i=4, j=5

i=4: nums[4]=5 < 6 → i++
i=5: nums[5]=4 < 6 → i++
i=6 > j=5，退出循环

swap(nums[3], nums[5]) → [1, 2, 3, 4, 5, 6]
返回 tmp=5
```

`tmp = 5 > target = 4`，目标在左边，`r = 4`。

**第三轮 partition**：`l = 3, r = 4`，随机选 pivot（假设选中 `nums[3] = 4`）：

```
当前: [1, 2, 3, 4, 5, 6]   pivot=4 换到最左（已在）
       i=4, j=4

i=4: nums[4]=5 ≥ 4 → 停
j=4: nums[4]=5 > 4 → j-- → j=3
i=4, j=3 → i≥j，退出循环

swap(nums[3], nums[3]) → 不变
返回 tmp=3
```

`tmp = 3 < target = 4`，`l = 4, r = 4`。

**第四轮 partition**：`l = r = 4`，直接返回 `tmp = 4`。

`tmp = 4 == target = 4`，返回 `nums[4] = 5`。

## 复杂度分析

| 版本 | 时间复杂度（期望） | 时间复杂度（最坏） | 空间复杂度 |
|:---:|:---:|:---:|:---:|
| 版本一 | O(n) | O(n²) | O(n) |
| 版本二 | O(n) | O(n²) | O(log n) |

- **期望 O(n)**：每次 partition 期望将数组减半，`n + n/2 + n/4 + ... = 2n`。随机 pivot 保证了这一点。
- **最坏 O(n²)**：如果每次 pivot 都是最小/最大元素（概率极低），退化为 O(n²)。
- 版本一空间 O(n)（每次递归创建三个新数组），版本二空间 O(log n)（递归栈深度）。若用 while 循环代替递归，版本二可进一步优化到 O(1) 空间。

---

## 总结

这道题是快速选择算法的经典模板，核心是**用 partition 缩小搜索范围**——和快速排序唯一的区别是，快排两边都要递归，而快速选择只递归目标所在的那一边。

两个版本对比：

- **版本一**（三路划分）：逻辑最直观，把数组分成大/等/小三个桶，根据 k 落入哪个桶决定递归方向。适合面试时快速写出。
- **版本二**（原地 partition）：标准快速选择写法，原地操作，空间更优。`part` 函数中的双指针相向扫描是快排的经典 partition 模板。

与 84. 柱状图中最大的矩形、739. 每日温度等单调栈题目不同，215 是 partition 思想的体现，属于"减治"（每次剔除一半候选）而非"单调性维护"。
