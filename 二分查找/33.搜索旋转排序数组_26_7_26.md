# 搜索旋转排序数组（Search in Rotated Sorted Array）题解

> 题目链接：[LeetCode 33. Search in Rotated Sorted Array](https://leetcode.cn/problems/search-in-rotated-sorted-array/)

## 题目描述

整数数组 `nums` 按升序排列，数组中的值互不相同。

在传递给函数之前，`nums` 在预先未知的某个下标 `k`（`0 <= k < nums.length`）上进行了**向左旋转**，使数组变为 `[nums[k], nums[k+1], ..., nums[n-1], nums[0], nums[1], ..., nums[k-1]]`（下标从 0 开始计数）。例如，`[0,1,2,4,5,6,7]` 在下标 3 上向左旋转后可能变为 `[4,5,6,7,0,1,2]`。

给你旋转后的数组 `nums` 和一个整数 `target`，如果 `nums` 中存在这个目标值 `target`，则返回它的下标，否则返回 `-1`。

你必须设计一个时间复杂度为 O(log n) 的算法解决此问题。

**示例 1：**

```
输入：nums = [4,5,6,7,0,1,2], target = 0
输出：4
```

**示例 2：**

```
输入：nums = [4,5,6,7,0,1,2], target = 3
输出：-1
```

**示例 3：**

```
输入：nums = [1], target = 0
输出：-1
```

---

## 核心思路

题目提示很明显了，O(log n)，向二分查找方向思考。

旋转后的数组有一个关键特征：它由两段**各自有序**的区间组成。比如 `[4,5,6,7,0,1,2]`，前半段 `[4,5,6,7]` 升序，后半段 `[0,1,2]` 升序，且前半段的所有元素都大于后半段。

我们发现，如果真的发生了旋转，约定数组的最大值下标为 **Max**，最小值为 **Min**，此时 **Min = Max + 1**。

并且我们发现，Max 作为数组中最大元素，我们可以通过二分查找法找出 Max 下标。约定初始 `l`、`r` 分别为首尾指针：

```cpp
while (l < r - 1) {
    int mid = l + (r - l) / 2;
    if (nums[mid] > nums[l] && nums[mid] > nums[r]) l = mid;
    else r = mid;
}
int maxIdx = l;
```

这样我们便找出了 Max，剩下的就不用多说了——根据 `target` 与 `nums[0]` 的关系，决定在左半段 `[0, maxIdx]` 还是右半段 `[maxIdx+1, n-1]` 做标准二分。

整体思路分三步：

1. **判断是否旋转**：`nums[0] <= nums[n-1]` 说明没旋转，全局二分即可。
2. **找旋转点 Max**：用二分定位最大值下标。
3. **分段二分**：在 `target` 所在的那一段做标准二分查找。

## 代码

```cpp
class Solution {
public:
    int search(vector<int>& nums, int target) {
        int l = 0, r = nums.size() - 1;

        // 未旋转或只有一个元素
        if (nums[l] <= nums[r]) {
            while (l <= r) {
                int mid = l + (r - l) / 2;
                if (nums[mid] == target) return mid;
                if (nums[mid] < target) l = mid + 1;
                else r = mid - 1;
            }
            return -1;
        }

        // 找到旋转点（最大值下标）
        while (l < r - 1) {
            int mid = l + (r - l) / 2;
            if (nums[mid] > nums[l] && nums[mid] > nums[r]) l = mid;
            else r = mid;
        }
        int maxIdx = l;   // 旋转点

        // 决定在左半还是右半查找
        if (target >= nums[0]) {
            l = 0; 
            r = maxIdx;
        } else {
            l = maxIdx + 1; 
            r = nums.size() - 1;
        }

        // 标准二分
        while (l <= r) {
            int mid = l + (r - l) / 2;
            if (nums[mid] == target) return mid;
            if (nums[mid] < target) l = mid + 1;
            else r = mid - 1;
        }
        return -1;
    }
};
```

## 代码分析

### 第一步：判断是否旋转

```cpp
if (nums[l] <= nums[r]) {
    // 全局二分...
}
```

旋转发生后，数组的第一个元素一定大于最后一个元素（左半段整体大于右半段）。所以 `nums[0] <= nums[n-1]` 意味着数组没有旋转，直接全局二分。这也顺带处理了 `n = 1` 的边界情况。

### 第二步：找旋转点 Max

这是整个算法的核心。旋转后的数组满足：**Max 在左半段，Min 在右半段，且 Min = Max + 1**。

我们维护 `l` 和 `r`，保证 `nums[l]` 始终在左半段（比 `nums[r]` 大），不断缩小区间直到 `l` 和 `r` 相邻——此时 `l` 就是 Max。

```cpp
while (l < r - 1) {
    int mid = l + (r - l) / 2;
    if (nums[mid] > nums[l] && nums[mid] > nums[r]) l = mid;
    else r = mid;
}
int maxIdx = l;
```

**判断条件 `nums[mid] > nums[l] && nums[mid] > nums[r]`** 的含义：`mid` 比两端都大，说明 `mid` 一定在左半段。此时最大值在 `mid` 或更右边，所以 `l = mid`。否则（`mid` 比两端都小，或者比 `nums[r]` 大但比不上 `nums[l]`），`mid` 在右半段，最大值在 `mid` 左边，所以 `r = mid`。

**为什么条件是 `l < r - 1` 而不是 `l <= r`？** 因为我们的目标是让 `l` 停在 Max 上、`r` 停在 Min 上，即 `l` 和 `r` 相邻时停止。如果条件是 `l <= r`，二分继续缩下去最终 `l == r`，无法区分谁大谁小。

以 `nums = [4,5,6,7,0,1,2]` 为例：

| 轮次 | l | r | mid | nums[mid] | > l 且 > r? | 操作 |
|------|---|---|-----|-----------|------------|------|
| 初始 | 0 | 6 | — | — | — | — |
| 1 | 0 | 6 | 3 | 7 | 7>4 且 7>2 ✓ | l=3 |
| 2 | 3 | 6 | 4 | 0 | 0<4 ✗ | r=4 |
| 3 | 3 | 4 | — | — | l 和 r 相邻，退出 | maxIdx=3 |

`maxIdx = 3`，即 `nums[3] = 7` 是 Max，`nums[4] = 0` 是 Min。

### 第三步：分段二分

找到了 Max，数组被切成了两段有序区间：

```
[4, 5, 6, 7]  |  [0, 1, 2]
 0         maxIdx  maxIdx+1    n-1
```

判断 `target` 落在哪一段：

```cpp
if (target >= nums[0]) {
    l = 0; 
    r = maxIdx;          // 左半段：[0, maxIdx]
} else {
    l = maxIdx + 1;      // 右半段：[maxIdx+1, n-1]
    r = nums.size() - 1;
}
```

`target >= nums[0]` → 在左半段（左半段所有元素都 ≥ `nums[0]`）；否则在右半段（右半段所有元素都 < `nums[0]`）。然后就是标准二分。

## 逐轮推演

以 `nums = [4,5,6,7,0,1,2], target = 0` 为例：

**步骤一**：`nums[0] = 4 > nums[6] = 2`，发生了旋转，进入步骤二。

**步骤二**：找 Max（如上表），`maxIdx = 3`。

**步骤三**：`target = 0 < nums[0] = 4`，在右半段查找。`l = 4, r = 6`。

| 轮次 | l | r | mid | nums[mid] | 比较 | 操作 |
|------|---|---|-----|-----------|------|------|
| 1 | 4 | 6 | 5 | 1 | 1 > 0 | r = 4 |
| 2 | 4 | 4 | 4 | 0 | 0 == 0 | 返回 4 |

返回 `4`。

## 复杂度分析

- **时间复杂度**：O(log n)。两步二分各 O(log n)，总体 O(log n)。
- **空间复杂度**：O(1)。只用了几个变量。

---

## 总结

这道题的核心是**把旋转数组拆成两段有序区间**，然后分别二分。关键步骤是找旋转点 Max——用二分定位最大值，判断条件是 `nums[mid] > nums[l] && nums[mid] > nums[r]`，mid 在左半段就向右缩（`l = mid`），在右半段就向左缩（`r = mid`），直到 `l` 和 `r` 相邻，此时 `l` 就是 Max，`r` 就是 Min。

这种「先定位 Max、再分段二分」的离线做法，逻辑清晰，找旋转点和二分查找各司其职，不容易出错。与在线做法（每次二分时判断 mid 落在哪一段再决定缩哪边）相比，思路更直观。
